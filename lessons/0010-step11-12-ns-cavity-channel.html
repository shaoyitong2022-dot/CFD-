Step 11+12 · 二维 Navier-Stokes：腔流与通道流

预计 75–90 分钟（A 轨大结局）｜ 教材：code\cfdpython-repo\lessons\14_Step_11.ipynb 与 15_Step_12.ipynb ｜ ← 前置 0009

✦ 本课收获（A 轨收官） ① 用前 10 课的积木搭出第一个 不可压 Navier-Stokes 求解器——腔流（lid-driven cavity）：盖子拖动、内部生旋涡；
② 理解投影法（pressure-Poisson）：动量更新半步 + 压力泊松迭代半部，二者交替；
③ 在 Step 12 体验周期边界与恒定驱动源项 $F$，把 0006 的周期边界、0009 的迭代法全串起来。

1 · 我们在解什么：不可压 NS 的三条方程

速度两个分量（u,v）+ 压力 p。动量守恒 + 连续性（质量守恒）：

$$ \frac{\partial u}{\partial t}+u\frac{\partial u}{\partial x}+v\frac{\partial u}{\partial y} =-\frac{1}{\rho}\frac{\partial p}{\partial x}+\nu\left(\frac{\partial^2u}{\partial x^2}+\frac{\partial^2u}{\partial y^2}\right) $$ $$ \frac{\partial v}{\partial t}+u\frac{\partial v}{\partial x}+v\frac{\partial v}{\partial y} =-\frac{1}{\rho}\frac{\partial p}{\partial y}+\nu\left(\frac{\partial^2v}{\partial x^2}+\frac{\partial^2v}{\partial y^2}\right) $$ $$ \frac{\partial^2p}{\partial x^2}+\frac{\partial^2p}{\partial y^2} =-\rho\left(\frac{\partial u}{\partial x}\frac{\partial u}{\partial x}+2\frac{\partial u}{\partial y}\frac{\partial v}{\partial x}+\frac{\partial v}{\partial y}\frac{\partial v}{\partial y}\right) $$
◆ 最难的一步：压力没有自己的演化方程 不可压意味着 $\nabla\cdot\vec{v}=0$ 是运动学约束而不是演化方程。压力的作用就是"时刻调整速度场，让散度为零"。把对动量方程取散度，才得到压力泊松方程（第三步）——这正是 0009 预告的用途。物理直觉：流场要"无源无汇"，压力像一只隐形的手，在每个格点按需要的量推挤流体，保证既不堆积也不真空。

教学建议（官方原话）：把上面三条方程手抄一遍，逐项对照 —— 每条项你都在 0003/0005/0007/0009 见过。

2 · 求解节奏（每一大时间步做两件事）

◆ 投影法两步节奏 设当前速度 $\vec{v}^n$。每一步：
① 动量半步：用 $\vec{v}^n$ 更新出"暂态速度"（不保证散度为零）——方程 1、2；
② 压力投影：求解压力泊松（用 build_up_b 组装右端、pressure_poisson 迭代），再用压力梯度修正速度，保证下步散度≈0。
顺序在代码里就是 build_up_b → pressure_poisson → 更新 u → 更新 v。

3 · 逐行注释：官方三函数

3.1 build_up_b：右侧那坨碎装腔

def build_up_b(b, rho, dt, u, v, dx, dy):
    # b 是压力泊松的"右端项"（公式第三行的括号内容×ρ）
    b[1:-1, 1:-1] = (rho * (1 / dt *
                    ((u[1:-1, 2:] - u[1:-1, 0:-2]) / (2 * dx) +
                     (v[2:, 1:-1] - v[0:-2, 1:-1]) / (2 * dy)) -
                    ((u[1:-1, 2:] - u[1:-1, 0:-2]) / (2 * dx))**2 -
                    2 * ((u[2:, 1:-1] - u[0:-2, 1:-1]) / (2 * dy) *
                         (v[1:-1, 2:] - v[1:-1, 0:-2]) / (2 * dx)) -
                    ((v[2:, 1:-1] - v[0:-2, 1:-1]) / (2 * dy))**2))
    #   ↑ ρ[ 1/Δt(∂u/∂x+∂v/∂y) - (∂u/∂x)² - 2(∂u/∂y)(∂v/∂x) - (∂v/∂y)² ]
    #     全部用中心差分(2Δx/2Δy)
    return b

四个括号从左到右逐个对应压力泊松 RHS 的四项：时间项（反映散度）、非线性平方项 ×3。它是"硬写容易错的一长串"，官方专门抽出函数防止拼写错误。

3.2 pressure_poisson：迭代求解 p（0009 的直接复用）

def pressure_poisson(p, dx, dy, b):
    pn = numpy.empty_like(p); pn = p.copy()
    for q in range(nit):                 # nit=50：内部子迭代（伪时间）
        pn = p.copy()
        p[1:-1, 1:-1] = (((pn[1:-1, 2:] + pn[1:-1, 0:-2]) * dy**2 +
                          (pn[2:, 1:-1] + pn[0:-2, 1:-1]) * dx**2) /
                         (2 * (dx**2 + dy**2)) -
                         dx**2 * dy**2 / (2 * (dx**2 + dy**2)) * b[1:-1,1:-1])
        # Poisson 五点模板 + 源项 —— 与 0009 的 Step 10 完全相同的结构
        p[:, -1] = p[:, -2]   # ∂p/∂x=0 @ x=2（Neumann，等于相邻列）
        p[0, :]  = p[1, :]    # ∂p/∂y=0 @ y=0
        p[:, 0]  = p[:, 1]    # ∂p/∂x=0 @ x=0
        p[-1, :] = 0          # p=0 @ y=2（参考压力零点）
    return p
◆ 为什么叫"填充压力泊松"？ 压力没有时间传播公式，要反复解泊松让它满足 $\nabla\cdot\vec{v}=0$。每步把 b（由当前速度算出）右端代入，迭代 50 次逼近一致。这个"0 阶精度 x 多次迭代"是腔流教学的标准折中。

3.3 cavity_flow：组装动量更新

def cavity_flow(nt, u, v, dt, dx, dy, p, rho, nu):
    un = numpy.empty_like(u); vn = numpy.empty_like(v)
    b = numpy.zeros((ny, nx))
    for n in range(nt):
        un = u.copy(); vn = v.copy()          # 快照
        b = build_up_b(b, rho, dt, u, v, dx, dy)   # ①压力RHS
        p = pressure_poisson(p, dx, dy, b)         # ②解压力
        # ③u 动量更新：五类项= 旧值 -x对流 -y对流 -压力梯度 + 黏性扩散
        u[1:-1, 1:-1] = (un[1:-1, 1:-1] -
                         un[1:-1, 1:-1] * dt / dx * (un[1:-1, 1:-1] - un[1:-1, 0:-2]) -
                         vn[1:-1, 1:-1] * dt / dy * (un[1:-1, 1:-1] - un[0:-2, 1:-1]) -
                         dt / (2 * rho * dx) * (p[1:-1, 2:] - p[1:-1, 0:-2]) +
                         nu * (dt / dx**2 * (un[1:-1, 2:] - 2*un[1:-1, 1:-1] + un[1:-1, 0:-2]) +
                               dt / dy**2 * (un[2:, 1:-1] - 2*un[1:-1, 1:-1] + un[0:-2, 1:-1])))
        # ④v 动量更新：结构相同，换成 v 和 y 方向压力梯度
        v[1:-1,1:-1] = (vn[1:-1, 1:-1] -
                        un[1:-1, 1:-1] * dt / dx * (vn[1:-1, 1:-1] - vn[1:-1, 0:-2]) -
                        vn[1:-1, 1:-1] * dt / dy * (vn[1:-1, 1:-1] - vn[0:-2, 1:-1]) -
                        dt / (2 * rho * dy) * (p[2:, 1:-1] - p[0:-2, 1:-1]) +
                        nu * (dt / dx**2 * (vn[1:-1, 2:] - 2*vn[1:-1, 1:-1] + vn[1:-1, 0:-2]) +
                              dt / dy**2 * (vn[2:, 1:-1] - 2*vn[1:-1, 1:-1] + vn[0:-2, 1:-1])))
        # ⑤边界：无滑移 u=v=0，盖子 u[-1,:]=1（唯一驱动）
        u[0, :] = 0; u[:, 0] = 0; u[:, -1] = 0
        u[-1, :] = 1                 # 盖子以 u=1 向右拖动
        v[0, :] = 0; v[-1, :] = 0; v[:, 0] = 0; v[:, -1] = 0
    return u, v, p
项代码片段对应
旧值un[1:-1,1:-1]$u^n$
x 对流un*dt/dx*(自-左邻)0007 非线性对流·x
y 对流vn*dt/dy*(自-上邻)0007 非线性对流·y
压力梯度dt/(2ρdx)*(右-左)新增：中心差分的 $-\frac{1}{\rho}\partial_x p$
黏性扩散νΔt/Δx²*(模板) + νΔt/Δy²*(模板)0008 二维扩散
◆ 唯一的"新东西"是压力梯度项与盖子 其余全部是复用。动量里唯一没见过的是压力梯度（中心差分、除以 2Δx/2Δy），边界唯一没见过的是"盖子"：u[-1,:]=1 让上边界以恒速拖动，撕扯下方流体、生成回转涡旋。这就是 lid-driven cavity 的全部"机关"。

4 · Step 12：通道流——周期边界 + 源项 F

改动极少：① u 动量方程右侧加恒定源项 $F$（模拟压降驱动）；② 边界改为 x 方向周期，上下壁面无滑移。

$$\text{u 方程} + F,\qquad \text{边界：}u(0)=u(2),\ v(0)=v(2),\ u,v=0\ @\ y=0,2,\ \partial p/\partial y=0\ @\ y=0,2$$
◆ F 的物理：为什么不能直接周期压力 官方 §Learn more 点破：真实管道流靠恒定压力梯度 $F=-\partial P/\partial x$ 驱动。但周期边界要求"左=右"，而压降恰恰要求左右压力不相等——所以把压力拆成 $p=P+p'$，恒定驱动写进动量方程的源项 $F$，把周期留给扰动 $p'$。这是个非常实用的建模技巧，值得在笔记里记一行。

Step 12 的代码几乎就是把 Step 11 的 build_up_b/pressure_poisson 改成周期版（含 x=0、x=2 边界的手写），u 更新末尾加 + F*dt。周期边界的处理方式和 0006 完全同思想——不是"设固定值"，而是"在每一轮更新里把左右边界当作邻居一样显式算"。

6 · 检查点：闭卷自测

Q1 · 投影法通过哪两个步骤保证速度场不可压？
①构建右端 b、求解压力泊松（让压力满足约束）；②用压力梯度修正动量更新后的速度，使其散度≈0。每步都做，环环相扣。
Q2 · build_up_b 里最左的括号 (1/Δt)(∂u/∂x+∂v/∂y) 物理代表什么？
反映流场瞬时的"膨胀率/散度"：因为压力要"纠正散度"，这项把当前速度场的散度用 1/Δt 尺度换算成压力源。它是把连续性约束渗进压力方程的关键项。
Q3 · 什么是"盖子"？它对流场做了什么？
上边界 u[-1,:]=1 恒速向右。黏性拖拽下方流体向右，箱子其他边界无滑移，四壁围出空间迫使流体回转，形成涡旋——lid-driven cavity 的招牌结构。
Q4 · Step 12 为什么给 u 方程加 F 而不直接周期化压力？
周期边界要求左右压力相等，与恒定压降矛盾。施加恒定压强梯度作为源项 F，压力分解 p=P+p'，周期放在 p' 上。既满足周期约束又模拟了真实驱动。
Q5（费曼）· 你怎么跟别人解释"不可压流场里压力是怎么被算出来的"？
参考表述：不可压就是"流不堆积"。速度在每一步算完后可能有一点散度（堆积），压力泊松方程会告诉你"该在每个地方施加多大的推挤"来把这点堆积抹掉；我们不知道压力本身，但通过解方程（用当前速度的散度作源）求出来它该是多少，这就是投影。
