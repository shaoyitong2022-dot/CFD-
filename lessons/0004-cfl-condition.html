CFL 条件：显式格式的生存法则

预计 40–50 分钟 ｜ 教材：code\cfdpython-repo\lessons\03_CFL_Condition.ipynb ｜ 前置 0002、0003 ｜ 术语表

✦ 本课收获 ① 亲手触发一次"数值爆炸"，并理解它为什么发生——这是 CFD 学生必吃的一课；
② 掌握 Courant 数 $\sigma=\frac{u\Delta t}{\Delta x}$ 与判据 $\sigma \le 1$，能当场口算并解释；
③ 学会把 $\Delta t$ "绑"在 $\Delta x$ 上（官方推荐的稳定写法），让代码不会因参数组合而炸。

1 · 先谈谈你已经悄悄踩过的坑

0002 实验 2 里，如果你把 dt=0.025 改大，可能已经看到数值解冒出锯齿、甚至输出 NaN。那不是 Bug，是格式的稳定性条件被突破了。这一课就是给它一个名字：CFL 条件（Courant–Friedrichs–Lewy，来自 1928 年那三位数学家的名字）。

◆ 稳定 ≠ 精确，先分清 "稳定"说的是：解不会无限放大、不会爆炸；"精确"说的是：解离真解有多近。CFL 管的是前一件事。一个格式可以稳定但不精确（比如迎风一阶的数值耗散），也可以精确但不稳定（比如下面你会看到的中心差分对流）——两者是不同维度的问题。

2 · 物理直觉：信息每步能传多远

把我们的代码换一种说法。每一层时间循环，我们做的是：看到当前时刻所有格点的 $u$，然后推断 $\Delta t$ 之后每个格点的新值。关键在于：这个推断要能完成，物理上得允许信息在 $\Delta t$ 内到达。

波以速度 $u$ 向右跑。一个时间步 $\Delta t$ 里，波移动了 $u\Delta t$ 的距离。网格里相邻两个点 $x_i$、$x_{i+1}$ 相距 $\Delta x$。现在问题来了：

  • 如果 $u\Delta t$ 小于或等于 $\Delta x$（一个时间步波最多跑一格）：信息总是"来得及"传到目标格点，格式可能稳定。
  • 如果 $u\Delta t$ 大于 $\Delta x$（一个时间步波跑过好几格）：我们只用了一格之内的信息去算 $\Delta t$ 后的值，信息事实上"追不上"——数学上这就触发不稳定的根源。

写成无量纲数（Courant 数，也称 CFL 数）：

$$ \sigma = \frac{u \Delta t}{\Delta x} $$

稳定性判据（对一维线性对流 + 迎风显式格式）：

$$ \sigma \le \sigma_{\max} , \qquad \sigma_{\max}=1 $$
◆ 记忆锚：σ 是"一个时间步内波能穿过几个格子"的度量 $\sigma=1$ 是极限：波恰好跑一个格子；$\sigma=0.5$：每步跑半格，稳妥；$\sigma>1$：波每步跑超过一个格子，数值解要炸。换句话说，显式格式的"世界速度极限"是一个时间步=一个格子。

3 · 亲手触发爆炸（官方同款实验）

官方把这个实验写成了一个函数 linearconv(nx)，方便只改 nx 去观察。第一步先用"固定 dt"版本复现爆炸：

import numpy
from matplotlib import pyplot
%matplotlib inline

def linearconv(nx):
    dx = 2 / (nx - 1)
    nt = 20
    dt = .025    # 固定 dt，不随 dx 变化  ← 问题的根源
    c = 1

    u = numpy.ones(nx)
    u[int(.5 / dx) : int(1 / dx + 1)] = 2

    un = numpy.ones(nx)

    for n in range(nt):
        un = u.copy()
        for i in range(1, nx):
            u[i] = un[i] - c * dt / dx * (un[i] - un[i-1])

    pyplot.plot(numpy.linspace(0, 2, nx), u)

linearconv(41)

现在依次执行 linearconv(61)、linearconv(71)、linearconv(85)。先预测，后运行。nx 增大 → $dx$ 变小 → 而 $dt=0.025$ 不变 → $\sigma=c\,dt/dx$ 不断变大。到 nx=85 时 $dx=2/84≈0.0238$，$\sigma≈1.05>1$——爆炸点。你看到的那个"和帽子毫无关系"的剧烈震荡图，就是数值不稳定的实况。

◆ 为什么 nx=85 时炸，71 不炸？算一遍给自己看 $dx(85)=2/84=0.02381$，$\sigma(85)=\frac{1\times0.025}{0.02381}=1.05>1$ 炸。
$dx(71)=2/70=0.02857$，$\sigma(71)=\frac{0.025}{0.02857}=0.875<1$ 稳。
边界就在 $\sigma=1$ 附近。口算这种数，是面试/组会被问 CFL 时的基本功。

4 · 正确写法：把 dt 绑到 dx 上

官方给出的修复非常简洁：给定 Courant 数 $\sigma$，让 $dt$ 由 $dx$ 自动推导：

$$ \Delta t = \sigma \frac{\Delta x}{u} $$

改后的函数（官方原版）：

import numpy
from matplotlib import pyplot

def linearconv(nx):
    dx = 2 / (nx - 1)
    nt = 20
    c = 1
    sigma = .5            # ← 想要的 Courant 数（稳定区间内随便选）
    dt = sigma * dx       # ← 关键修复：dt 跟随 dx，σ 恒为 0.5

    u = numpy.ones(nx)
    u[int(.5 / dx) : int(1 / dx + 1)] = 2

    un = numpy.ones(nx)

    for n in range(nt):
        un = u.copy()
        for i in range(1, nx):
            u[i] = un[i] - c * dt / dx * (un[i] - un[i-1])

    pyplot.plot(numpy.linspace(0, 2, nx), u)

隔一行 `dt = sigma * dx`，就同时实现了两个目标：无论 nx 多大都稳定，且 Courant 数可显式控制。跑 linearconv(41/61/81/101/121) 全部稳定。

◆ 但多了一个新现象 注意官方提示：网格越密，冒出来的帽形整体移动得越短。为什么？nt 固定是 20，但 $dt$ 随 $dx$ 变小了 → 总模拟时长 $nt\cdot dt$ 也变小 → 波走得总距离变短，这是"模拟更短的时间"而"不是"波变慢了。这是网格收敛讨论里的常客，后面步进 2D 时会再次相见。

5 · 检查点：闭卷自测

Q1 · 写出 Courant 数定义，以及一维迎风显式格式的稳定性判据。
$\sigma=\frac{u\Delta t}{\Delta x}=\frac{c\Delta t}{\Delta x}$，判据 $\sigma\le1$（=1 是极限）。用语言说：一个时间步里波移动的距离不能超过一个网格宽度。
Q2 · nx=85、dt=0.025、c=1，σ 是多少？稳定吗？
$dx=2/84≈0.02381$，$\sigma=0.025/0.02381≈1.05>1$，不稳定——这就是官方实验里看到爆炸的那个组合。
Q3 · 网格翻倍（nx 41→81），若 dt 不变、c 不变，σ 怎么变？
dx 减半 → σ 变为原来的 2 倍。所以"加密网格"如果不配 dt 相应减小，反而更容易不稳定。这正是"dt 必须绑在 dx 上"的原因。
Q4 · 为了让 σ=0.5，当 dx=0.01 时 dt 应是多少（u=1）？
$dt = \sigma\frac{dx}{u} = 0.5\times0.01=0.005$。这就是官方代码里 dt = sigma * dx 那一行的含义。
Q5（费曼）· 向一个只会用 Mathematica 符号计算的同学解释：为什么显式时间推进有个"每步不超过一个网格"的速度极限？
参考表述：电脑只能在网格点上取值，一次时间步之后，每个格点的新值只能由它"够得着"的邻居算出；波一个时间步走的路程若超过一个网格，就超出了这个点信息能到达的范围，数值解于是失去因果联系、开始乱震（不稳）。要稳，就得让波每步最多走一格，也就是 σ≤1。
