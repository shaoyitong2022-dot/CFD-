◆ 课前补给 · 二维里的积木组装

上一课你做到：升到了二维，学会用切片替代循环。→ 这一课往前一步：在二维里把两种过程再组装一次。

代码补给⑧（broadcasting）：形状不同的数组做运算时，NumPy 自动把小的那个"扩"到匹配——所以一个标量能直接乘上整个数组，不用写循环。

u[1:-1,1:-1] = (un[1:-1,1:-1]
                 - un[1:-1,1:-1]*dt/dx*(un[1:-1,1:-1]-un[:-2,1:-1])   # x 方向对流
                 - un[1:-1,1:-1]*dt/dy*(un[1:-1,1:-1]-un[1:-1,:-2])   # y 方向对流
                 + nu*dt/dx**2*(un[2:,1:-1]-2*un[1:-1,1:-1]+un[:-2,1:-1]))  # 扩散

物理补给⑧（二维拉普拉斯）：$\nabla^2=\partial_x^2+\partial_y^2$——两个方向各算一次再相加。
扩散是各向同性的：它没有偏爱方向，所以用的是中心差分（对称），而不是对流那种有方向的迎风格式。

✦ 本课收获 ① 把一维扩散公式推广到二维（两个二阶导相加），并掌握 2D 扩散的稳定取法（含 dx*dy 组合）；
② 完成 Step 8：二维 Burgers 方程（非线性对流 + 扩散全耦合）——你的 Burgers 主线 FDM 基准至此成型。
◆ 物理补强｜本课会用到的流体力学基石 本课不需要新的物理概念，只要把扩散正式放到二维：
  • 拉普拉斯 $\nabla^2$ = 两个方向凹凸之和：二维扩散方程 $\partial_t u=\nu\nabla^2 u$ 里 $\nabla^2u=\partial^2_x u+\partial^2_y u$。它回答"$u$ 在这点整体（各方向加总）有多凸"，是各向同性的——抹平方向不偏爱 $x$ 或 $y$。
  • 和各向异性对流相反：对流有明确方向（沿 $\vec u$），所以有迎风；扩散没有方向偏好，所以用对称的中心差分。这两种模板的差别在整个 CFD 里贯穿。
  • 二维稳定约束更严：每个方向各有一条 $\Delta t\le \frac12\Delta x^2/\nu$，二维同时要两条都满足，所以官方用到 dx*dy 的组合取法。
与代码的关系：$u_{i,j}=u_{i,j} + \frac{\nu\Delta t}{\Delta x^2}(u_{i+1,j}-2u_{i,j}+u_{i-1,j}) + \frac{\nu\Delta t}{\Delta y^2}(u_{i,j+1}-2u_{i,j}+u_{i,j-1})$——就是"$x$ 方向凹凸 + $y$ 方向凹凸"，每根括号就是 0005 那个一维模板在一个轴上的复用。

1 · Step 7：二维扩散

方程：

$$ \frac{\partial u}{\partial t} = \nu\frac{\partial^2u}{\partial x^2} + \nu\frac{\partial^2u}{\partial y^2} $$

二阶导在二维照搬一维中心差分（0005 学的模板），x、y 各来一遍相加：

$$ u_{i,j}^{n+1} = u_{i,j}^n + \frac{\nu\Delta t}{\Delta x^2}(u_{i+1,j}^n-2u_{i,j}^n+u_{i-1,j}^n) + \frac{\nu\Delta t}{\Delta y^2}(u_{i,j+1}^n-2u_{i,j}^n+u_{i,j-1}^n) $$

稳定取法（区别于 1D）

2D 扩散的稳定边界更紧，官方便捷取法：

$$ \sigma = \frac{\nu \Delta t}{\Delta x\,\Delta y} \le \frac14 \quad(\text{官方取 }0.25),\qquad \Delta t = \sigma\frac{\Delta x\,\Delta y}{\nu} $$
◆ 2D 的稳定"变严"来自两个方向同时扩散 一维是 $\frac{\nu\Delta t}{\Delta x^2}\le\frac12$；到 2D 每方向都扩散，允许的 $\Delta t$ 更小。官方代码直接 dt = sigma * dx * dy / nu（注意是 dx*dy 的分子组合）。看到这个式子，就认出这是"2D 扩散版稳定取法"。

逐行注释：官方向量版核心

nx = 31; ny = 31; nt = 17; nu = .05
dx = 2/(nx-1); dy = 2/(ny-1)
sigma = .25
dt = sigma * dx * dy / nu    # 2D 扩散稳定取法

u = numpy.ones((ny,nx)); un = numpy.ones((ny,nx))
u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2   # 帽子

def diffuse(nt):                     # 官方封装成函数，便于多次调用
    u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2  # reset 初始帽子
    for n in range(nt + 1):
        un = u.copy()
        # x 方向二阶导 + y 方向二阶导
        u[1:-1, 1:-1] = (un[1:-1,1:-1] +
                        nu * dt / dx**2 * (un[1:-1, 2:] - 2*un[1:-1,1:-1] + un[1:-1, 0:-2]) +
                        nu * dt / dy**2 * (un[2:,1:-1] - 2*un[1:-1,1:-1] + un[0:-2,1:-1]))
        # ↑内部区        ↑旧值            ↑x 二阶差分模板（右-2中+左）       ↑y 二阶差分模板（下-2中+上）
        u[0,:]=1; u[-1,:]=1; u[:,0]=1; u[:,-1]=1   # 四边固定 1
    return u   # 然后 3D 画图见官方（meshgrid + plot_surface）
切片含义
un[1:-1, 2:]去掉首尾行、去掉前两列 = "右邻居"区（i+1）
un[1:-1, 0:-2]去掉首尾行、去掉后两列 = "左邻居"区（i-1）
un[2:, 1:-1]去掉前两行、去掉首尾列 = "下邻居"区（j+1）
un[0:-2, 1:-1]去掉后两行、去掉首尾列 = "上邻居"区（j-1）

u[1:-1, 1:-1] 是"去掉四边后的内部"，更新的正好是它——四边留给边界赋值。对照模板：中心系数 -2（两个 2*un[1:-1,1:-1]），一个来自 x、一个来自 y。

官方调用 diffuse(10)、diffuse(14)、diffuse(50)，你会看到帽子随时间被抹平、慢慢变成整片 1——二维的"盒子里的墨迹扩散"。

2 · Step 8：二维 Burgers（里程碑）

这就是"把 0006 的一维 Burgers（对流+扩散）变成二维 + u/v 两分量"。它的重要性在官方原话里说得很清楚："contains the full convective nonlinearity of the flow equations"——你把流体微元的"自我对流 + 自身扩散"全都解过了。

耦合方程组（u、v 各自满足 Burger 型）——只写 u 的更新公式：

$$ \begin{split} u_{i,j}^{n+1} = u_{i,j}^n &- \frac{\Delta t}{\Delta x}u_{i,j}^n(u_{i,j}^n-u_{i-1,j}^n) - \frac{\Delta t}{\Delta y}v_{i,j}^n(u_{i,j}^n-u_{i,j-1}^n)\\ &+ \frac{\nu\Delta t}{\Delta x^2}(u_{i+1,j}^n-2u_{i,j}^n+u_{i-1,j}^n) + \frac{\nu\Delta t}{\Delta y^2}(u_{i,j+1}^n-2u_{i,j}^n+u_{i,j-1}^n) \end{split} $$

它的代码 = 0007 的耦合对流 + 0007 的二维扩散，拼起来。这一课你其实是"组装旧零件"，不是学新概念——这正是官方说的 code reuse。

逐行注释：官方向量版核心

nx = 41; ny = 41; nt = 120
dx = 2/(nx-1); dy = 2/(ny-1)
sigma = .0009;  nu = 0.01
dt = sigma * dx * dy / nu    # 注意：这里按 2D 扩散的稳定取法

u = numpy.ones((ny,nx)); v = numpy.ones((ny,nx))
un = numpy.ones((ny,nx)); vn = numpy.ones((ny,nx))
u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2   # u 帽子
v[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2   # v 帽子

for n in range(nt + 1):
    un = u.copy(); vn = v.copy()

    u[1:-1, 1:-1] = (un[1:-1, 1:-1] -                    # 旧值 u^n
                     dt/dx * un[1:-1,1:-1] * (un[1:-1,1:-1] - un[1:-1, 0:-2]) -   # x 非线性对流
                     dt/dy * vn[1:-1,1:-1] * (un[1:-1,1:-1] - un[0:-2,1:-1]) +    # y 非线性对流
                     nu*dt/dx**2 * (un[1:-1,2:] - 2*un[1:-1,1:-1] + un[1:-1,0:-2]) +  # x 扩散
                     nu*dt/dy**2 * (un[2:,1:-1] - 2*un[1:-1,1:-1] + un[0:-2,1:-1]))   # y 扩散

    # v 方程：把上面 5 项里的"被搬运/被扩散的量"换 v 即可
    v[1:-1, 1:-1] = (vn[1:-1, 1:-1] -
                     dt/dx * un[1:-1,1:-1] * (vn[1:-1,1:-1] - vn[1:-1, 0:-2]) -
                     dt/dy * vn[1:-1,1:-1] * (vn[1:-1,1:-1] - vn[0:-2,1:-1]) +
                     nu*dt/dx**2 * (vn[1:-1,2:] - 2*vn[1:-1,1:-1] + vn[1:-1,0:-2]) +
                     nu*dt/dy**2 * (vn[2:,1:-1] - 2*vn[1:-1,1:-1] + vn[0:-2,1:-1]))

    u[0,:]=1; u[-1,:]=1; u[:,0]=1; u[:,-1]=1   # u 四边固定 1
    v[0,:]=1; v[-1,:]=1; v[:,0]=1; v[:,-1]=1   # v 四边固定 1
◆ 一行都不改的复用清单 x 非线性对流 = 0007 的 Step 6 那项；y 非线性对流 = 0007 那项；两个扩散项 = 正是本课 Step 7 那两项。所谓"写自己的 NS 求解器"，本质就是把这几块积木按正确顺序排好——现在你手里有全部积木了。

观察结果图：两个帽子在二维平面里被"冲"成团——非线性让它们变形前进，扩散让它们糊开。从初始平滑到实际成形，渐显 2D 的冲击波雏形。

4 · 检查点：闭卷自测

Q1 · 2D 扩散稳定取法（用 σ 表示 dt）与 1D 有何不同？
2D：$\Delta t = \sigma\frac{\Delta x\,\Delta y}{\nu}$（σ 取 0.25，安全域）；1D：$\Delta t = \sigma\frac{\Delta x^2}{\nu}$（σ 取 0.2）。差别在分子 $\Delta x\Delta y$ vs $\Delta x^2$——2D 两个方向同时扩散，时间步要更保守。
Q2 · 二维二阶差分模板把 -2 出现在哪里？为什么？
x、y 两个方向各自模板的中间项都含 $-2u_{i,j}$，代码里对应两个独立的 2*un[1:-1,1:-1]。看到两个 -2*中心 就是二维二阶导的签名。
Q3 · Step 8 的 u 更新公式里，哪些项用 un、哪些用 vn？为什么？
x 方向自身搬运用 un（速度=u），y 方向被 v 搬运用 vn，两个扩散项也都用 un（被扩散的是 u 本身）。v 方程同理倒过来。用哪份快照取决于"谁是搬运者、谁是被搬运的量"。
Q4 · 为什么 Step 8 的 dt 用扩散稳定取法（dx*dy分子）而不是对流 CFL？
Step 8 同时含对流和扩散两项；显式格式的时间步要同时满足两者。实际操作中按较"严"的那个取（扩散的分子 dx*dy 的保守式），官方 sigma=.0009 把 dt 取得很小，安全。
Q5（费曼）· 一句话说清"二维 Burgers 比一维多了什么"到只懂一维的同学。
参考表述：一维只有"沿一根线的自己冲自己"，二维变成一片液态表面，每个方向都有场把自己推着走，还互相交叉搬运（v 推 u、u 推 v），同时向四面八方扩散。物理上就是"水流"的骨架。
