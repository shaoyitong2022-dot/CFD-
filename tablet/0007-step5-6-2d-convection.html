Step 5+6 · 二维对流：从一根线到一片场

预计 50–60 分钟 ｜ 教材：code\cfdpython-repo\lessons\07_Step_5.ipynb 与 08_Step_6.ipynb ｜ ← 前置 0006

✦ 今日战果 ① 掌握二维网格的关键约定：u[j, i]（j=y、i=x）与三维绘图 meshgrid + plot_surface；
② 把一维对流公式"平移"到二维（只多一项 $\partial_y$），并看到帽子在一个平面里被搬动；
③ 对比两层 for 循环与数组运算（向量化）两种写法，为后面所有步奠定"少写循环"的习惯。

1 · 二维的约定（本节最容易踩坑的地方）

二维就多一个下标。约定（钉死它，后面全用）：

  • 网格 $nx$ 列（x 方向，下标 i）、$ny$ 行（y 方向，下标 j）；
  • 数组形状 (ny, nx)（先写行数再写列数！）；
  • 访问元素 u[j, i]：第一个是行 = y，第二个是列 = x。
◆ 为什么先 ny 后 nx？ numpy 数组第一维是"行"（y），第二维是"列"（x），所以 numpy.ones((ny, nx))。一旦反过来，plot_surface(X, Y, u) 会转置——你画出来的帽子方向就歪了。写错这个 ny, nx 顺序是 2D 阶段头号 Bug。

二维偏导的定义一句话：对 $x$ 求偏导就是"保持 $y$ 不变"。所以一维的所有差分公式原样照搬，只是每个量都多了个 $j$ 下标。

2 · Step 5：二维线性对流

方程（比一维多一项）：

$$ \frac{\partial u}{\partial t} + c\frac{\partial u}{\partial x} + c\frac{\partial u}{\partial y} = 0 $$

离散后（$x$ 用后向、$y$ 用后向，都迎风格式）：

$$ u_{i,j}^{n+1} = u_{i,j}^n - c\frac{\Delta t}{\Delta x}(u_{i,j}^n-u_{i-1,j}^n) - c\frac{\Delta t}{\Delta y}(u_{i,j}^n-u_{i,j-1}^n) $$

逐行注释：官方原版（for 循环版）

from mpl_toolkits.mplot3d import Axes3D   # 三维绘图需要
import numpy
from matplotlib import pyplot, cm
%matplotlib inline

nx = 81; ny = 81     # x、y 各有 81 个格点
nt = 100;  c = 1     # 100 时间步；波速
dx = 2 / (nx - 1)    # Δx，域宽 2
dy = 2 / (ny - 1)    # Δy，域高 2
sigma = .2           # Courant 数（0004 学过）
dt = sigma * dx      # 时间步由 CFL 反推，保证稳定

x = numpy.linspace(0, 2, nx)    # x 坐标向量
y = numpy.linspace(0, 2, ny)    # y 坐标向量

u = numpy.ones((ny, nx))        # 二维场，先全 1
un = numpy.ones((ny, nx))       # 临时场

### 帽子：0.5≤x≤1 且 0.5≤y≤1 → 2（二维版切片）
u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2

### 三维画初始条件
fig = pyplot.figure(figsize=(11,7), dpi=100)
ax = fig.add_subplot(projection='3d')   # 新 matplotlib 写法（旧 gca(projection='3d') 已废弃）
X, Y = numpy.meshgrid(x, y)     # 生成网格坐标（二维绘图必须用 meshgrid）
surf = ax.plot_surface(X, Y, u[:], cmap=cm.viridis)

meshgrid(x, y) 返回两个二维矩阵 X、Y：X 每行都是 x、Y 每列都是 y，两者一起铺满整片网格，供 plot_surface 定位每个数据点。dpi 和 figsize 只是显示参数。

主循环（两层 for 遍历全网格）：

for n in range(nt + 1):        # 注意 nt+1：含第 nt 步
    un = u.copy()
    row, col = u.shape         # row=ny, col=nx —— 正好记住 (ny,nx)
    for j in range(1, row):    # 外层 j：y 方向（行），跳过 j=0
        for i in range(1, col):# 内层 i：x 方向（列），跳过 i=0
            u[j, i] = (un[j, i] - (c * dt / dx * (un[j, i] - un[j, i-1])) -
                                  (c * dt / dy * (un[j, i] - un[j-1, i])))
            #          ↑新值     ↑x 方向对流(=cΔt/Δx × 我-左邻居)  ↑y 方向对流
            # 边界：最外层四个边强制为 1
            u[0, :]  = 1   # y=0（顶排）
            u[-1, :] = 1   # y=2（底排）
            u[:, 0]  = 1   # x=0（左列）
            u[:, -1] = 1   # x=2（右列）
◆ 二维"跳过边界"的规律 内层 range(1, ...) 跳过 i=0 和 j=0（因为要读左邻居/上邻居），边界四边在循环外直接赋值 1。这是二维对一维规律的直接推广——内部点自己算，边界点手动设。

3 · 关键升级：数组运算（向量化）替代循环

同一个计算，去掉两层 for 的写法：

u = numpy.ones((ny, nx))
u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2

for n in range(nt + 1):
    un = u.copy()
    u[1:, 1:] = (un[1:, 1:] - (c * dt / dx * (un[1:, 1:] - un[1:, :-1])) -
                              (c * dt / dy * (un[1:, 1:] - un[:-1, 1:])))
    #  ↑右下内区      ↑右下内区       ↑x 项：本区 - 左移一列([:-1])   ↑y 项：本区 - 上移一行([:-1, :])
    u[0, :]  = 1; u[-1, :] = 1; u[:, 0] = 1; u[:, -1] = 1

逐段翻译：

切片作用
u[1:, 1:]"除去第一行第一列的内部"矩形区（对应 j≥1,i≥1）
un[1:, :-1]un 去掉第一行、去掉最后一列 = "左邻居"矩形区（i-1）
un[:-1, 1:]un 去掉最后一行、去掉第一列 = "上邻居"矩形区（j-1）

这是一次性把"全部内部格点"同时更新，numpy 在 C 层面替你循环——快上百倍，而且和 for 循环结果是逐元素相等的。官方在 Step 5 结尾专门演示了这版。以后所有步我都给你"循环版（便于对公式）"和"向量版（实际快）"两种，务必看懂后一种。

4 · Step 6：二维非线性对流（u、v 耦合）

这是"把 Step 2 变二维"，同时要解两个耦合场：

$$ \frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} = 0,\qquad \frac{\partial v}{\partial t} + u\frac{\partial v}{\partial x} + v\frac{\partial v}{\partial y} = 0 $$

离散（只挑 $u$ 方程的更新公式，$v$ 完全同构）：

$$ u_{i,j}^{n+1} = u_{i,j}^n - u_{i,j}^n\frac{\Delta t}{\Delta x}(u_{i,j}^n-u_{i-1,j}^n) - v_{i,j}^n\frac{\Delta t}{\Delta y}(u_{i,j}^n-u_{i,j-1}^n) $$
◆ 关键认知：对流速度是向量 (u,v) 在二维，$u$ 不止被 $u$ 自己搬运，还被垂直方向的速度 $v$ 搬运。所以 $u$ 方程的对流项里出现 v，$v$ 方程里出现 u——这就是"耦合"（coupled）。代码里 u、v 必须同时推进、共用同一组快照 un、vn。

逐行注释：官方向量版核心

nx = 101; ny = 101; nt = 80; c = 1
dx = 2/(nx-1); dy = 2/(ny-1); sigma = .2; dt = sigma*dx

u = numpy.ones((ny,nx)); v = numpy.ones((ny,nx))
un = numpy.ones((ny,nx)); vn = numpy.ones((ny,nx))
u[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2  # u 的帽子
v[int(.5/dy):int(1/dy+1), int(.5/dx):int(1/dx+1)] = 2  # v 的帽子（初始相同）

for n in range(nt + 1):
    un = u.copy(); vn = v.copy()      # 两场同时快照

    # u 方程：非线性对流两方向
    u[1:, 1:] = (un[1:, 1:] -
                 (un[1:, 1:] * c * dt / dx * (un[1:, 1:] - un[1:, :-1])) -
                  vn[1:, 1:] * c * dt / dy * (un[1:, 1:] - un[:-1, 1:]))
    # v 方程：结构完全相同，把被搬运的场换 v
    v[1:, 1:] = (vn[1:, 1:] -
                 (un[1:, 1:] * c * dt / dx * (vn[1:, 1:] - vn[1:, :-1])) -
                  vn[1:, 1:] * c * dt / dy * (vn[1:, 1:] - vn[:-1, 1:]))

    # 四个边界，u、v 都固定为 1
    u[0,:]=1; u[-1,:]=1; u[:,0]=1; u[:,-1]=1
    v[0,:]=1; v[-1,:]=1; v[:,0]=1; v[:,-1]=1
行对应公式说明
un[1:,1:] * c*dt/dx * (un[1:,1:]-un[1:,:-1])$u_{i,j}^n\frac{\Delta t}{\Delta x}(u_{i,j}^n-u_{i-1,j}^n)$x 方向非线性对流（速度 = 当地 u）
vn[1:,1:] * c*dt/dy * (un[1:,1:]-un[:-1,1:])$v_{i,j}^n\frac{\Delta t}{\Delta y}(u_{i,j}^n-u_{i,j-1}^n)$y 方向非线性对流（速度 = 当地 v）
v 方程几乎复制粘贴把上表三个 u 换成 v耦合体现在：速度场仍用 un、vn

6 · 检查点：闭卷自测

Q1 · u[j,i] 中 j 和 i 分别对应哪个方向？数组形状怎么定义？
j = y（行），i = x（列）；数组 numpy.ones((ny, nx))——先 ny 后 nx。搞反会导致绘图转置、帽子方位错误。
Q2 · 二维线性对流比一维多哪一项？
多 $-c\frac{\Delta t}{\Delta y}(u_{i,j}^n-u_{i,j-1}^n)$，即 y 方向的后向差分对流项。x、y 两个方向各自独立离散，只是求和了。
Q3 · 向量化写法中 un[1:, :-1] 代表什么？
un 去掉第一行、去掉最后一列后剩下的矩形——正好是"每个内部点的 x 方向左邻居"拼成的矩阵。用切片表达"整块左移"是向量化的核心技巧。
Q4 · Step 6 的 u 方程里为什么出现 v？出现哪些项？
u 在 y 方向被 v 搬运，所以 y 方向对流项用 v 当速度。同理，v 方程的 y 项用 v、x 项用 u。两场交叉搬运＝耦合。
Q5（费曼）· 向只知道一维数组的同学解释：为什么二维绘图需要 meshgrid？
plot_surface 需要给每个数据点一个 (x, y) 坐标；meshgrid 把一维的 x 和 y 各复制成二维矩阵，行列交叉出整片网格坐标，plot_surface 才能知道每个 u[j,i] 该放在哪里。
