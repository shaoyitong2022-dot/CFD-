✦ 本课收获 ① 亲手解决"一维主线"的终极方程 Burgers 方程（非线性对流 + 扩散合体）——课程主线中的 Burgers 主线 FDM 基准在此刻诞生；
② 学会用 Sympy 做符号微分，再 lambdify 成可调用函数（科研里超常用的"推导交给机器"套路）；
③ 搞懂周期边界条件：右端出去的量从左边回来，以及它如何让"头痛"的边界在代码里露出马脚。
◆ 物理补强｜本课会用到的流体力学基石 Burgers 是理解真实流动的"最小模型"，补这一课核心的一条对立：
  • 一对基本矛盾：对流制造陡坡，扩散把它磨平：非线性对流（0003）把波形搓陡、要形成激波；扩散（0005）专治尖锐。二者同时存在，谁强谁弱决定解长什么样——这是几乎所有流动的母题。
  • 激波 vs 黏性后厚度：若没有扩散，非线性会让剖面无限变陡（走向间断的激波）。加上黏性 $\nu$ 后，陡坡被限制在某个有限宽度里，形成"黏性激波"——这也是为什么真实流动不会有无限零的密度梯度。
  • 雷诺数雏形（比值思想的登场）：对流项与扩散项谁的贡献大，用一个比值衡量 $\mathrm{Re}=\frac{\text{惯性(对流)}}{\text{黏性(扩散)}}$。Burgers 里局部比值用 $u/\nu$ 的量纲组合就能体现"对流相对扩散有多占优"——雷诺数家族的入门直觉，后面 N-S（0010）正式登场。
与代码的关系：本课把 0003 的对流模板 + 0005 的扩散模板直接相加，就是 Burgers 的离散式。改变 $\nu$ 你就会看到"陡峭锯齿"和"平滑波形"之间的切换——那就是对流/扩散谁占上风的最直观演示。

1 · Burgers 是什么

一句话：非线性对流 + 扩散，正是你学过的 Step 2 和 Step 3 的合体：

$$ \frac{\partial u}{\partial t} + u\frac{\partial u}{\partial x} = \nu\frac{\partial^2u}{\partial x^2} $$

左一项：非线性对流（快追慢，制造陡坡）；右一项：扩散（把陡坡抚平）。两个相反的作用打架，形成所谓"saw-tooth"（锯齿）演化。这个方程虽小，却是好东西：它有解析解，方便你做精确对照——这在 CFD 里极其珍贵（真实流动几乎都没有解析解）。

◆ 为什么 Burgers 是"主线" 你的课程主线中"Burgers 主线"指的就是这一课。它包含了一个完整 PDE 求解器的全部要素：非线性项、二阶导数、复杂初始/边界条件、解析解对照。跑通它 = 有资格进军 2D 和 NS。今天这一课的成果将是后续 PINN 课程（B 轨）的对比基准——同一个方程，之后用神经网络解，你就能看懂"FDM 基线"多值钱。

2 · 初始/边界条件：比帽子有趣得多

官方这次换掉帽子，改用能显示冲击波的初始条件。初始（t=0）：

$$ \phi(x,0) = \exp\left(\frac{-x^2}{4\nu}\right) + \exp\left(\frac{-(x-2\pi)^2}{4\nu}\right), \qquad u(x,0) = -\frac{2\nu}{\phi}\frac{\partial\phi}{\partial x} + 4 $$

解析解（任意 t）：

$$ \phi(x,t) = \exp\left(\frac{-(x-4t)^2}{4\nu(t+1)}\right) + \exp\left(\frac{-(x-4t-2\pi)^2}{4\nu(t+1)}\right), \qquad u(x,t) = -\frac{2\nu}{\phi}\frac{\partial\phi}{\partial x} + 4 $$

边界：周期边界 $u(0)=u(2\pi)$——右端溢出的量绕回左端。这会引出全课最狡猾的坑（§4 揭晓）。

追根问底：这个 φ 到底是什么？（Cole–Hopf 变换）

看到那两个高斯函数的和，第一反应通常是"这初始条件哪来的"。答案是：它是倒着造出来的。

Burgers 方程含 $u\,u_x$ 这一非线性项，绝大多数初始条件都求不出解析解。但 Cole 和 Hopf 发现了一个"作弊"式的替换——令

$$ u = -2\nu\,\frac{\phi_x}{\phi} $$

把它代回 Burgers 方程，非线性项会被消掉，方程退化为

$$ \frac{\partial\phi}{\partial t} = \nu\frac{\partial^2\phi}{\partial x^2} $$

这正是 0005 学过的纯扩散方程。而扩散方程我们熟：随便丢一堆高斯包进去，它怎么演化都能写下来。

于是流程被反过来走：

  1. 先随手挑一个 φ——这里选两个高斯包的和，因为它明显满足扩散方程；
  2. 再用 $u=-2\nu\phi_x/\phi$ 算出对应的 u，就得到一个精确满足 Burgers 方程的解；
  3. 取它在 t=0 时的样子作为初始条件；后面任意时刻的值，直接把 t 代进那个含 $(x-4t)$ 的 φ 表达式即可。

换句话说：不是"先有初始条件，碰巧有解析解"，而是"先要造一个解析解，再倒推出初始条件"。那一坨高斯不是物理设计，是出题设计。

◆ 那个 +4 和 (x−4t) 里的 4 是同一件事 给 u 整体加常数 4，等价于换一个以速度 4 平移的参考系（Galilean 变换），波形整体向右漂移。看 φ 表达式里的 $(x-4t)$ 就明白了：波包中心以速度 4 右移。
所以这个解描述的是一个一边演化、一边整体平移的波形——这也是为什么后来会看到漂亮的锯齿在向右推进。

为什么要用 Sympy？

$\partial_x\phi$ 手算容易漏符号、漏系数（官方原话："it would be easy to drop a sign or forget a factor of x"）。Sympy 替你求导、渲染成 $\LaTeX$，再 lambdify 成数值函数——这是把"符号推导"和"数值计算"接起来的标准桥梁，将来推导复杂通量时极有用。

3.1 Sympy 求导

import numpy
import sympy
from sympy import init_printing
init_printing(use_latex=True)     # 让 Sympy 输出用 LaTeX 渲染

x, nu, t = sympy.symbols('x nu t')   # 声明三个符号变量

phi = (sympy.exp(-(x - 4*t)**2 / (4*nu*(t+1))) +
       sympy.exp(-(x - 4*t - 2*sympy.pi)**2 / (4*nu*(t+1))))
phi

sympy.symbols('x nu t') 一次声明三个符号。`**` 在 Sympy 里也代表幂。整个 phi 是一个 Sympy 表达式对象，屏幕会渲染成漂亮的数学式。

phiprime = phi.diff(x)     # 对 x 求偏导，一行搞定
phiprime                    # 显示结果
from sympy.utilities.lambdify import lambdify

u = -2 * nu * (phiprime / phi) + 4   # 纯符号表达式构造 u
ufunc = lambdify((t, x, nu), u)      # ← 关键：转成可调用数值函数
print(ufunc(1, 4, 3))                # 代入 t=1,x=4,nu=3 测试
行干什么为什么
phi.diff(x)符号求 ∂φ/∂xSympy 自动链式求导，无手算错误
u = -2*nu*(phiprime/phi) + 4把初始条件拼成符号表达式复用了 phiprime 和 phi——符号运算让"拼式子"也零错误
lambdify((t, x, nu), u)符号 → 数值函数参数顺序明确：(t,x,nu)，之后调用 ufunc(t_val, x_val, nu_val)

numpy.asarray([ufunc(t, x0, nu) for x0 in x])：列表推导逐个 x0 调数值函数，生成数组。这是"把符号解变成网格点数值"的惯用写法。

3.2 补 · dt = dx * nu 到底是什么来头

前面 0004、0005 一直教一套正统做法：先定稳定因子 σ，再反推 dt。结果这课突然冒出一句 dt = dx * nu 且不解释，很容易让人怀疑前面白学了。其实它一点也不神秘，把它代回 0004 的 Courant 数看看：

$$ \sigma_c=\frac{u\,\Delta t}{\Delta x}=\frac{u\,(\Delta x\cdot\nu)}{\Delta x}=u\,\nu $$

Δx 被约掉了。所以这个取法的真实含义是：让 Courant 数直接等于 $u\nu$，与网格无关。本课的 u 最大值约为 7（实测初始场落在 1.0～7.0 之间），ν=0.07，于是

$$ \sigma_c \approx 7 \times 0.07 = 0.49 $$

刚好压在 CFL 上限 1 以内。再看 0005 的扩散稳定因子：

$$ \sigma_d=\frac{\nu\,\Delta t}{\Delta x^2}=\frac{\nu^2}{\Delta x}=\frac{0.07^2}{0.0628}\approx 0.078 $$

离上限 0.5 很远。于是得出一个有用的结论：本课真正的紧约束是对流项（σ_c 用到了 0.49），扩散项非常宽松（σ_d 只有 0.078）。官方是在"两个条件都刚好满足"的前提下，挑了 ν=0.07 配 dt=dx·ν 这一组。

⚠ 但这个 dt 有隐患，值得自己跑一遍验证 注意 $\sigma_d=\nu^2/\Delta x$：分母是一次方的 Δx，所以网格越密它反而越大——这和直觉正好相反。保持 ν=0.07、dt=dx·ν 不变，只加密网格，实测结果如下：
nxΔxσ_d跑 100 步后
1010.06280.078稳定
2010.03140.156稳定
4010.01570.312稳定
6410.00980.499失稳（刚好顶到上限）
8010.00790.624失稳（溢出成 inf）
结论很清楚：dt = dx*nu 只是这一组参数碰巧能跑，网格一加密就作废。而 0005 那套"先定 σ 再反推 dt"让 σ 不随网格变化，才是能扛住网格细化的做法。亲手验证见实验 4。

3.2 补 · 一个很容易踩的 Python 陷阱：t 被覆盖了

这段代码里 t 出现了两种截然不同的身份：

x, nu, t = sympy.symbols('x nu t')   # ① 这里的 t 是 Sympy 符号
...
t = 0                                 # ② 这里的 t 变成了普通整数 0
u = numpy.asarray([ufunc(t, x0, nu) for x0 in x])

符号变量被普通数字覆盖了，为什么没报错？因为 lambdify 在那之前已经把表达式"烤"成了一个独立的数值函数，它接收参数只按位置对应 (t, x, nu)，压根不关心外面的 t 是谁。所以 ② 之后传给 ufunc 的就是数字 0。

代价是：从这一行起 t 不再是符号了。此时若再写 phi.diff(t)，会报 'int' object has no attribute 之类的错。想在后面继续做符号运算，就得换个名字，例如 t_sym = sympy.symbols('t')。

这是 Sympy 新手最常见的坑之一，官方 notebook 自己也这么写——能看懂它在干什么就算过关。

3.3 主循环：挑战在周期边界

for n in range(nt):
    un = u.copy()
    for i in range(1, nx-1):      # 内层跳过两端（和 Step 3 一样，因要读 un[i+1]）
        u[i] = un[i] - un[i] * dt / dx * (un[i] - un[i-1]) + \
               nu * dt / dx**2 * (un[i+1] - 2*un[i] + un[i-1])
        #       ↑对流项（Step 2）        ↑扩散项（Step 3）

    # ← 关键：内层循环没覆盖 i=0 和 i=nx-1，周期边界在这补
    u[0] = un[0] - un[0] * dt / dx * (un[0] - un[-2]) + \
           nu * dt / dx**2 * (un[1] - 2*un[0] + un[-2])
    #      ↑ i=0 的对流"左邻居"是 un[-2]（因为 u[-1]=u[0]，真正的"左边"是倒数第二点）
    u[-1] = u[0]                # 周期:右端点=左端点
◆ 周期边界的"头痛"点 第一，un[-2]：在周期世界，i=0 的左邻居不是数组尾的假值，而是 un[-2]（倒数第二点），因为 un[-1] 被约定等于 un[0]。
第二，右端 u[-1] = u[0]：设置周期，让最后一点跟第一点同步。
第三：内层 range(1, nx-1) 的范围很关键——若你写成 range(1, nx)，到 i=nx-1 时读 un[i+1]=un[nx] 会越界，这就是官方说"will cause you a bit of headache"的地方。

3.4 解析解对照（代码可复现的独特之处）

u_analytical = numpy.asarray([ufunc(nt * dt, xi, nu) for xi in x])  # 解析解：t=nt*dt

pyplot.figure(figsize=(11, 7), dpi=100)
pyplot.plot(x, u, marker='o', lw=2, label='Computational')
pyplot.plot(x, u_analytical, label='Analytical')
pyplot.xlim([0, 2*numpy.pi])
pyplot.ylim([0, 10])
pyplot.legend()

两条线几近重合——你手写的求解器逼近了解析解。这种"数值 vs 解析"并排，是验证算法正确性的金标准。

5 · 检查点：闭卷自测

Q1 · 写出 Burgers 方程的更新公式（含对流项与扩散项）。
$u_i^{n+1}=u_i^n-u_i^n\frac{\Delta t}{\Delta x}(u_i^n-u_{i-1}^n)+\nu\frac{\Delta t}{\Delta x^2}(u_{i+1}^n-2u_i^n+u_{i-1}^n)$。对照代码：第二项是对流（0002），第三项是扩散（0005）。
Q2 · 周期边界条件下，i=0 的对流"左邻居"为什么是 un[-2] 而不是 un[-1]？
约定 u[-1]=u[0]（周期），所以点 0 的"左边真正邻居"是倒数第二点 u[-2]；若用 un[-1] 会把它当成左邻居，引入错误。这也是官方提醒"周期边界头痛"的所在。
Q3 · lambdify 的作用是什么？为什么要用它？
把 Sympy 的符号表达式转成可调用的数值函数，以便批量代入 numpy 网格值（栅格化）。没有它，符号表达式不能直接对数组求值。
Q4 · Burgers 方程为什么会自生"锯齿"（steepening）现象？
非线性对流项（快追慢）持续堆陡前缘，而扩散项试图抹平；当扩散不够大时，波形会不断变陡并可能形成近间断的"冲击波"。解析解精确预测了这个演化，所以数值解能与它对照。
Q5（费曼）· 为什么把内层循环写成 range(0, nx) 会出错？
因为更新公式要读 un[i+1]：i=nx-1 时下标越界。同时周期边界需要专门的 i=0/i-1 补写；把 range 写成 0..nx 既越界又没体现周期。边界是周期的事情，代码结构上要跟"内部点"分开处理。
Q6 · 本课那一坨看起来很怪的初始条件，是怎么来的？（讲清楚构造顺序）
顺序是反的。先构造函数 φ（两个高斯包的和，它满足纯扩散方程），再用 Cole–Hopf 变换 $u=-2\nu\phi_x/\phi$ 算出对应的 u，这才得到一个精确满足 Burgers 方程的解；取 t=0 那一份作为初始条件。目的不是"设计一个漂亮初值"，而是让这道题存在能对照的精确解。
Q7 · 为什么本课可以写 dt = dx*nu？它的隐患是什么？
因为代入后 Courant 数 $\sigma_c=u\,\Delta t/\Delta x=u\nu$，Δx 被约掉，与网格无关；ν=0.07、u_max≈7 时 σ_c≈0.49，压在 CFL 上限内。隐患在扩散侧：$\sigma_d=\nu^2/\Delta x$ 的分母是一次方的 Δx，网格越密反而越大——实测 nx=641 时 σ_d 就达到 0.499 顶格并开始溢出。所以它只在特定网格下碰巧成立，不如"先定 σ 再反推 dt"可靠。
Q8 · 这段代码里 t 为什么既是符号又可以是数字？
sympy.symbols 造出的 t 是符号；后来 t = 0 把它覆盖成普通整数。没报错是因为 lambdify 早已把表达式转成独立数值函数，按位置而非名字接收参数。副作用是从此 t 不再是符号，phi.diff(t) 会报错；想继续符号运算要另起名字。
