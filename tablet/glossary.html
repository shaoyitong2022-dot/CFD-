A 轨 · 数值方法（CFDPython）

有限差分 finite difference, FD
用相邻网格点上函数值的差商近似导数：$\frac{\partial u}{\partial x}\approx\frac{u_{i+1}-u_i}{\Delta x}$（向前差分）。整个 CFDPython 课程的地基。
网格 grid / mesh
把连续时空切成离散点阵：空间步长 $\Delta x$、时间步长 $\Delta t$。计算机不认识连续世界，只认识网格。
初值条件 IC, initial condition / 边界条件 BC, boundary condition
PDE 的"起跑线"与"围栏"。IC 给 $t=0$ 时刻的场；BC 给计算域边缘的约束（Dirichlet 定值 / Neumann 定梯度 / 周期）。
CFL 条件 Courant–Friedrichs–Lewy condition
显式格式的稳定性红线：信息在一个时间步内走过的物理距离不能超过一个网格宽，$C=\frac{u\Delta t}{\Delta x}\le 1$。超过它，数值解震荡发散。
Courant 数 Courant number
即上面的无量纲数 $C$，又称 CFL 数。C=1 是"刚好踩着信息传播速度"的极限状态。
数值耗散 numerical diffusion / dissipation
低阶格式把尖锐波抹平的倾向——数值解表现得更"黏"。Step 1 里方波跑着跑着变斜坡就是它。
数值色散 numerical dispersion
不同频率的波以不同数值速度传播，导致波前振荡、拖尾（非物理的"涟漪"）。
迎风格式 upwind scheme
导数差分方向顺流场方向取（风从左边来，就向左边的点取差分），让格式稳定。CFDPython Step 1 对流项用的是空间后向差分（取 $i-1$），配合时间前向差分，正是迎风思想的最小体现。
通量 flux
物理量穿过单位截面的输运率（质量/动量/能量）。守恒律 PDE 的标准写法 $\partial_t u + \nabla\cdot F = 0$ 中的一切都在 $F$ 里。
收敛阶 order of accuracy
网格减半时误差下降的幂次：一阶 $O(\Delta x)$ 误差减半，二阶 $O(\Delta x^2)$ 误差降为四分之一。中心差分二阶，向前差分一阶。
FTBS / FTCS
格式命名的四字密码：F=Forward（时间向前），T=Taylor/时间层，B=Backward（空间向后），C=Centered（空间居中）。FTBS=时间前向+空间后向=迎风；FTCS=时间前向+空间居中（扩散问题常用）。
双曲 / 抛物 / 椭圆 hyperbolic / parabolic / elliptic
PDE 三大类型。对流方程（双曲）传信息、扩散方程（抛物）抹平信息、Laplace 方程（椭圆）全局瞬时平衡。分别对应 Step 1–2、Step 3、Step 9–10。
压力泊松方程 pressure Poisson equation
不可压 NS 的核心 trick：速度散度为零的约束可改写成关于压力的椭圆方程，Step 11 腔流的主角。
向量化 vectorization
用 NumPy 整数组运算替代 Python for 循环，把循环下放到 C 层执行，典型加速 100 倍。CFDPython 前半程用循环讲概念，后半程全部向量化重写。

B 轨 · 机器学习（谐振子 PINN）

自动微分 automatic differentiation, autograd
程序化地对复合函数求精确导数，机器是"对计算图求导"而非数值差商。PyTorch 的 torch.autograd.grad 是其在课中的入口。
计算图 computational graph
神经网络前向传播记录下来的运算 DAG。反传 loss 时沿图回溯自动算出所有参数梯度。create_graph=True 的含义：把求导过程本身也记入图，这样导数还能再求导（二阶导）。
残差 residual
把试探解代入方程后剩下的"没被满足的部分"。谐振子中 $r = m\ddot{x}+\mu\dot{x}+kx$，精确解时 $r\equiv 0$。
物理损失 physics loss
残差平方和在采样点上的均值 $\frac{1}{N}\sum r_i^2$。PINN 的"物理"二字全部落在这里：网络被迫学一个让方程几乎成立的函数。
数据损失 data loss
网络输出与观测点的均方误差（普通监督学习那一项）。总损失 $=$ 数据项 $+$ 权重 $\times$ 物理项，权重平衡是 PINN 训练的头号玄学。
PINN physics-informed neural network
把已知微分方程作为软约束写进损失函数的神经网络（Raissi et al. 2019）。既能当 PDE 求解器（正向），也能反演方程参数（逆向）。
插值 vs 外推 interpolation vs extrapolation
裸 NN 只会插值——训练数据覆盖范围内有效；PINN 靠方程约束获得外推能力：数据没覆盖的区域物理定律仍然成立。
