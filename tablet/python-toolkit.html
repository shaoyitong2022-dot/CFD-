1 · 数组创建：zeros / ones / empty / linspace

写法干什么什么时候用
numpy.zeros(n)长度 n、全 0要累加、有默认值的安全起点
numpy.ones(n)长度 n、全 1均匀背景场（0005 的帽子就是在一片 1 上放一段 2）
numpy.empty(n)长度 n、内容未定义马上要被完全覆盖时（省掉一次清零）
numpy.linspace(a,b,n)a→b 之间均匀取 n 个点生成空间坐标 x
◆ empty 的坑（0006 里出现过） numpy.empty(nx) 不清零，它拿到的可能是上一块内存里的垃圾值。课上敢这么写，是因为紧接着 un = u.copy() 会把每个元素都覆盖掉。
判据：empty 出来的数组，每个位置你确定都要写——才用它。否则用 zeros。

2 · copy()：本门课最容易犯的静默错误

un = u            # ✗ 危险：un 只是 u 的另一个名字
un = u.copy()     # ✓ 正确：真正的副本

NumPy 的赋值是「贴标签」，不是「复制箱子」。两个名字指向同一块内存，改其中一个，另一个跟着变。

为什么时间推进必须要 copy()：更新公式右边用的全是上一时刻的值 $u^n$，左边写的是新值 $u^{n+1}$。如果 un 和 u 是同一个数组，你更新到一半，右边读到的就已经是被污染的新值了。

⚠ 这个错误不报错 它不会抛异常，只会让结果悄悄地错——图画出来往往还"看着挺像回事"。所以每写一层 for 循环，都先问自己一句：这一行右边，需要的是上一时刻的值吗？是，就必须 copy。

3 · 负索引与切片

写法含义本课出现在哪
u[-1]最后一个元素0006 周期边界：u[-1] = u[0]
u[-2]倒数第二个0006：周期世界里 i=0 真正的左邻居
u[1:-1]去掉两端，取中间0007 起替代内层循环的向量化写法
u[:-2]从第 0 个到倒数第三个切片更新里的"左邻居整体"

4 · 向量化：从双层循环到一行切片

下面两段代码完全等价，左边是 A 轨前半段（0002–0006）的写法，右边是 0007 之后的写法：

# 逐点循环（更好懂）
for i in range(1, nx-1):
    u[i] = un[i] - un[i]*dt/dx*(un[i]-un[i-1])

# 切片整体运算（更短、更快）
u[1:-1] = un[1:-1] - un[1:-1]*dt/dx*(un[1:-1]-un[:-2])

切片写法的关键：把"每个点的邻居"也整体平移一格——un[i-1] 对应全体平移后的 un[:-2]。这是因为数组的每个元素同时扮演"自己"和"别人的邻居"两个角色。

5 · 列表推导 + asarray：符号 → 数值的最后一公里

u = numpy.asarray([ufunc(t, x0, nu) for x0 in x])

读法：对 x 里的每个 x0，算出对应的 ufunc(...)，收集成 Python 列表，再用 asarray 变成 NumPy 数组。
这是把「一个含 t/x/ν 的数学函数」铺到网格点上的标准做法（0006 生成初始场和解析解都在用）。

6 · SymPy 三件套

写法干什么
sympy.symbols('x nu t')声明符号变量（此后它们是"代数字母"，不是数字）
expr.diff(x)对 x 符号求导，自动链式法则
lambdify((t,x,nu), expr)把符号表达式编译成可调用的数值函数
⚠ 变量覆盖陷阱（官方代码也这么写，但你要看懂） 
x, nu, t = sympy.symbols('x nu t')   # t 是符号
t = 0                                 # ← t 变成普通整数 0
之所以不报错：lambdify 早已把表达式"烤"成独立函数，它按位置而非名字接收参数。
代价：此后 t 不再是符号，phi.diff(t) 会报错。要继续符号运算就另起名字，如 t_sym。

7 · Matplotlib 最小可用集

pyplot.figure(figsize=(11, 7))   # 画布
pyplot.plot(x, u, marker='o', lw=2, label='数值')  # 画线
pyplot.xlim([0, 2]); pyplot.ylim([0, 10])          # 坐标范围
pyplot.legend()                                     # 显示图例
pyplot.subplot(1, 2, 1)          # 子图：1行2列第1个

# 三维（新版 API，务必用这个）
ax = fig.add_subplot(projection='3d')

旧写法 fig.gca(projection='3d') 在 matplotlib 3.10 已废弃，会报 TypeError。官方 2013 年的 notebook 里还有这种写法，遇到直接换成上面的。

8 · %matplotlib inline 是什么

它是 Jupyter 的魔法命令（不是 Python 语法），让图画在单元格下方直接显示。放在 import 区即可。在 PyCharm 的 .py 文件里不需要也不能写。

9 · 报错速查

报错通常原因
IndexError: index out of bounds循环写成了 range(1, nx)，末尾读了 un[nx]
ValueError: operands could not be broadcast两个数组形状对不上（比如 u[1:-1] 和 un[:-1] 长度不同）
'int' object has no attribute 'diff'符号变量被数字覆盖了（见第 6 节）
结果不对但不报错多半是漏了 copy()（见第 2 节）
