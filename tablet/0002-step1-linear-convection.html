Lesson 0002 · Phase A 第 1 课

Step 1 · 一维线性对流：你的第一个差分求解器

预计 40–50 分钟 ｜ 教材：code\cfdpython-repo\lessons\01_Step_1.ipynb ｜ 术语表

✦ 本课收获（两个） ① 亲手把人生第一个 PDE 离散成可在电脑上计算的公式，并用两层循环写成一个能跑的数值求解器；
② 亲眼看到初始的"方帽"在传播中变形——并知道这是数值耗散在作祟（这是后面所有课的引子）。

1 · 我们先说清楚：这条方程在讲什么

这条方程只有两个速度，却承载了 CFD 一半的核心直觉：

$$ \frac{\partial u}{\partial t} + c\frac{\partial u}{\partial x} = 0 $$

每个部分的意思：

  • $\frac{\partial u}{\partial t}$：u 这一"场"（比如水的速度、污染物的浓度）随时间怎么变；
  • $c\frac{\partial u}{\partial x}$：场随位置的变化沿速度为 $c$ 的方向被搬运——这叫对流（convection）；
  • 整条式子的含义：某一点的场之所以变化，唯一原因是"上游的东西被搬运过来了"，于是 $u$ 的形状保持原样但整体向右平移，速度就是 $c$。
◆ 为什么叫"线性" 方程里 $u$ 只出现一次且都在分子的线性位置，没有 $u^2$、没有 $\sin u$。线性方程有个上帝保佑的性质：形状不变、只是平移。Step 2 把 $c$ 换成 $u$ 自己（$\partial_t u + u\partial_x u=0$），就立刻变成非线性——那时候形状就会自我撕裂。先记住：线性 = 搬运不变形。

如果 $u_0(x)$ 是 $t=0$ 初始的形状，那么方程精确解是：

$$u(x, t) = u_0(x - ct)$$

一个公式概括全部：$t$ 时刻在 $x$ 处看到的东西 = 初始时刻在 $x-ct$ 处的东西，因为那团东西沿 $x$ 方向已平移了 $ct$。记住这个"解析解"，后面验证代码全靠它。

2 · 把方程变成计算机能算的东西（慢动作离散）

连续世界计算机看不懂，必须切成网格。网格是什么？把 $x$ 轴切成 $n_x-1$ 段，得到 $n_x$ 个点，编号 $i=0,1,\dots,n_x-1$。相邻两点距离 $\Delta x$，相邻两个离散时刻距离 $\Delta t$。

用导数的定义、直接扔掉取极限那一步：

$$\frac{\partial u}{\partial t} \approx \frac{u_i^{n+1} - u_i^{n}}{\Delta t}, \qquad \frac{\partial u}{\partial x} \approx \frac{u_i^{n} - u_{i-1}^{n}}{\Delta x}$$

三处值得停下来说：

  • 时间导数是"前向"差分：用 $n$ 和 $n+1$ 两层，因为我们想从当前时刻推出未来——这正是求解器的目的；
  • 空间导数是"后向"差分：用 $i$ 和 $i-1$ 两个点，即"向左边取点"。原因马上见图——因为波向右走，上游（左边）才是信息的来源，这叫迎风（upwind）；
  • 上标是时间层（$n$），下标是空间格点（$i$）。后面代码里记忆法：上标靠循环外圈 $n$，下标靠内圈 $i$。

把两式代入原方程并解出唯一未知量 $u_i^{n+1}$，得到更新公式——这就是你在代码里将要写的那一行：

$$ u_i^{n+1} = u_i^{n} - c\frac{\Delta t}{\Delta x}(u_i^{n} - u_{i-1}^{n}) $$

解读：新值 $u_i^{n+1}$ = 旧值 $u_i^{n}$ −（搬运量）。搬运量正比于 $c$、正比于时间步 $\Delta t$、反比于网格 $\Delta x$，还正比于"我自己 − 左边邻居"的差值。数学推导这一步，验证标准：合上书，能独立从原方程推出这一行。

◆ 为什么空间差分要"向后取"，不一碗水端平？ 物理直觉：$u$ 以速度 $c$ 向右搬运，所以 $x_i$ 处的信息来自它的上游（左边 $x_{i-1}$），而不是下游（右边 $x_{i+1}$）。方向取错了，格式会不稳定、数值解"爆炸"（这会亲自炸给你看，就在本课 §4 实验 3）。后面的 CFL 专章会从数学上严格证明这件事。

3 · 逐行注释：把更新公式翻译成 Python

先记两个小事：官方课程把 NumPy 写成 import numpy（写代码时都得写全 numpy），业界更流行 import numpy as np。为了和你复现官方代码一一对应，本课用官方的写法，后面向量化课再统一换成 np。
每次条件独立：手打，不要复制。打一行想一行——这是你代码弱最直接的补法。

3.1 参数区：定义网格和时间步

nx = 41            # 空间格点数：x 方向切 40 段
dx = 2 / (nx - 1)  # 每段长度 = 总长 2 除以段数 40 = 0.05
nt = 25            # 时间步数：整个模拟推进 25 步
dt = .025          # 每步的时间跨度 Δt
c = 1              # 波的传播速度
代码它到底在干什么对应公式
dx = 2 / (nx-1)全是 41 个点，但首尾之间有 40 个间隔，所以是除以 nx-1 而不是 nx。$\Delta x$
nt = 25外层循环将执行 25 次，每次把整根"线"推进 0.025 秒，总共推进 25×0.025=0.625 秒。循环次数
dt = 0.025一个时间步走 0.025 秒。$c=1$ 意味着每一步波移动 0.025 米。$\Delta t$
c = 1波速归一化，方便检验：25 步后应该向右移动 0.625。$c$

3.2 初始条件：造一个大礼帽

u = numpy.ones(nx)                    # 一维数组，全部置 1（长度 nx）
u[int(.5 / dx):int(1 / dx + 1)] = 2   # 把下标 int(0.5/dx) 到 int(1/dx) 之间的格子改成 2
print(u)

这是全课最容易懵的一行，拆开解剖：

  • numpy.ones(nx)：生成长度 41 的数组，元素全为 1。数组下标 0~40 对应 $x=0$~$2$。
  • 0.5 / dx = 0.5/0.05 = 10.0，int(10.0)=10：$x=0.5$ 落在下标 10。
  • 1 / dx + 1 = 1/0.05+1=21，int(21)=21。注意这里手动 +1：因为 Python 切片 a[10:21] 取下标 10~20（右端点 21 不含），要覆盖到 $x=1$ 对应的下标 20，右端必须写 21。
  • 于是下标 10~20 共 11 个格子 = 物理区间 $[0.5, 1]$，被赋值成 2；其余保持 1。帽子就这么诞生：左一半是 1，中间是 2，右一半是 1。
◆ int() 在这里的阴险之处 如果 $0.5/dx$ 不是整数（比如你把 nx 改成别的值），int() 会直接截断小数，帽子就悄悄偏离 0.5——这就是官方让你改 41 时"发生了什么"的一半原因。改 nx 时留意帽子边缘是否仍对齐 0.5。

3.3 观察帽子

pyplot.plot(numpy.linspace(0, 2, nx), u);

官方在这里故意留了个问题：为什么帽子两侧不是笔直的竖线？答案：初始条件在格点上本来就是"一排 1、一排 2、一排 1"，每一排之间是垂直跳变的；plot 只是用直线把相邻数据点连起来，41 个点之间的线段把台阶画成了斜坡。帽子在数据层面是笔直的，是画图让肉眼看斜了。

跑出图后停一下，把帽子的位置和 §2 里"帽子在 $[0.5,1]$"对一眼，确认下标↔坐标的对应。这个"坐标手感"后面 12 步都要用。

3.4 主循环：把更新公式搬到 for 循环里

这是求解器的灵魂，逐行注释：

un = numpy.ones(nx)          # 临时数组 un：准备装"下一步的 u"
                             # （先随意填 1，循环里会立刻被真值覆盖）

for n in range(nt):          # 外层循环：n = 0,1,...,24，共 25 个时间步
    un = u.copy()            # 关键！把当前 u 整体复制给 un
                             # 为什么必须 copy()？见下：'un = u' 只复制"名字"，不复制数据
    for i in range(1, nx):   # 内层循环：i = 1,...,40

        u[i] = un[i] - c * dt / dx * (un[i] - un[i-1])
        #      ↑更新公式，逐词对照：
        #     u_i^{n+1}    = u_i^n   -  c  * dt/dx *     (u_i^n  -  u_{i-1}^n)
        #     新值          旧值           搬运量          我 - 左边邻居

三个"为什么"必须当场答出来（这是本课检查点的主问题）：

问题答案
为什么是 un = u.copy()，而不是 un = u？un = u 让两个名字指向同一块内存；循环内一旦改了 u[i]，un 也变，公式里本该用"上一步"取值就乱了。必须 copy() 出一份独立副本，un 永远代表"上一步 $u^n$"。
为什么内层从 range(1, nx) 开始，跳过 i=0？更新公式要用 un[i-1]；若 i=0，un[-1] 是数组"最后一个元素"（Python 负下标特性），把它当左邻居是个 Bug。跳过它，等于把空间边界固定在第 0 格。
为什么内层循环的更新用 un 里读值、写进 u？同一时间步内，格点之间的更新必须彼此独立：都用同一步的旧值（un）计算，写到新数组（u）。如果边算边用新值，就是"以更新过的值再算"，物理上变成不同步——这是时间推进正确性的关键。
◆ 一个烧脑的伏笔 上面最后一条"必须用 un 里的旧值"——如果不用 copy、边算边覆盖，就是典型的错误写法，这个坑你会在后面自己踩到。官方用 $u^n$ / $u^{n+1}$ 两层来避免。写循环时的一律原则：读旧数组、写新数组。

3.5 再看一眼：帽子跑起来的样子

pyplot.plot(numpy.linspace(0, 2, nx), u);

帽子明显向右移动了（这正是 $c=1$ 的对流），但它不再是帽子：两侧变圆、顶部变低、后面拖了小尾巴。官方问：发生了什么？——这是本课最核心的问题，答案在 §4 实验 3 里揭晓。

4 · 三个必做实验（改参数，观察，解释）

每次改参数前，先合上笔记本，口头预测会发生什么，再运行验证——这是"变参数预测"。

实验 1：加密网格 nx=41 → 81

网格变密后帽子更细分。重点观察两点：帽子的水平位置有没有动（应该还在 $[0.5,1]$，因为切片用 dx 重新算了位置）和边缘的分辨率。同时留意：加密后物理的 $\Delta x$ 变小，但 $\Delta t$ 没变——这已经在悄悄改变一个叫 CFL 数的量，它决定了稳定性（0004 专章）。

实验 2：加大时间步 dt=0.025 → 0.1

Δt 放大 4 倍。小心——若直接运行，你很可能看到数值解开始震荡、发散甚至爆炸。这不是 Bug，是格式不稳定：一个时间步里波移动的距离（$c\Delta t = 0.1$）超过了半个网格宽度（$\Delta x/2 = 0.025$），信息流速快过网格能传递的速度，数值解就"疯了"。这个临界判断就是 CFL 条件，0004 课正式登场。

实验 3：把内层改成 range(0, nx)（或删掉迎风格式）

如果内层从 0 开始（等于把 un[-1] 当左邻居），帽子边缘会怎样？如果再把空间差分改成"向前取点"（用 un[i+1]-un[i] 代替 un[i]-un[i-1]）——会让格式失去迎风性，右边邻居（下游）成了信息来源，与波的传播方向相反，通常立刻不稳定。试完把结果记下来，这是"为什么迎风"的最好实证。

◆ 实验 2、3 的账，留到 0004 付 如果你在实验里看到了震荡/爆炸，先用一句话记录它长什么样（"波形出现锯齿"还是"直接炸成 NaN"），然后把参数改回去继续。CFL 专章会给出严格判据 $C=\frac{c\Delta t}{\Delta x}\le 1$ 和理论解释。现在只要建立"这个开关是稳定性"的直觉。

5 · 检查点：闭卷自测（合上笔记本回答）

Q1 · 写出线性对流方程的更新公式（这个必须闭卷默写）。
$u_i^{n+1}=u_i^{n}-c\frac{\Delta t}{\Delta x}(u_i^{n}-u_{i-1}^{n})$。默写时检查三点：系数 $c\Delta t/\Delta x$、括号里是"自己减左边邻居"、下标是 $i$ 和 $i-1$（迎风）。
Q2 · 为什么空间差分要用后向（取 $i-1$ 而非 $i+1$）？换成 $i+1$ 会发生什么？
波向右移动，$x_i$ 处的信息来自上游（左邻居 $x_{i-1}$），用下游（$i+1$）违背物理方向，格式通常不稳定、数值解震荡或发散。迎风方向的直觉就是"信息从哪儿来，就从哪儿取点"。
Q3 · un = u.copy() 和 un = u 有何本质区别？为什么必须用前者？
un = u 只是让两个名字指向同一个数组（改一个、另一个跟着变）；copy() 复制一份独立数据。没 copy 的话，循环里更新了 u[i]，un 也变，公式里的"上一步值"就被污染了——时间推进彻底错乱。
Q4 · 为什么 dx = 2/(nx-1) 而不是 2/nx？
41 个点之间只有 40 个间隔，$\Delta x$=总长/间隔数，所以除的是 $\text{nx}-1$。把 41 改成 81 时同理要算 80。
Q5（费曼题）· 向一个不会数值计算的同学解释：为什么初始是"方帽"，跑 25 步后变"圆顶"？
参考表述：因为我们只在有限的格点上采样，格点之间用直线连起来，而一阶格式的"离散误差"会让尖锐的跳跃被抹平（人为黏性/数值耗散）——网格越粗、抹得越狠。它向右传送是对的（物理是 $c=1$ 每秒平移 0.625），但形状会受损；精细网格（实验 1）能减缓损伤。
Q6 · 预测实验：把 dt 从小调大（0.025→0.1），相同 nx=41，你预期图会怎样？
预期：数值解开始振荡、出现锯齿，甚至最终发散成 NaN。因为 $c\Delta t$（0.1）超过了 $\Delta x$（0.05）能承受的信息传播范围，稳定性判据被打破——CFL 数 >1。若没预期到这一点，恰恰是这节课要补的认知盲区。
