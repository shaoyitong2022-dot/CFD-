◆ 课前补给 · 不演化的方程

上一课你做到：二维的演化方程都会解了。→ 这一课往前一步：换一类方程——不随时间演化，直接求终态。

代码补给⑨（while 与收敛判据）：

while numpy.linalg.norm(u - un, 1) > tol:    # 迭代到"变化足够小"才停
    un = u.copy()
    ...

演化方程用 for n in range(nt)（跑固定步数）；稳态问题用 while（跑到收敛）。这个区别就是抛物型与椭圆型的分野。

物理补给⑨（散度与稳态）：散度 $\nabla\cdot\vec u$ 度量净流出。稳态场不随时间变（$\partial_t=0$），Poisson 方程描述的就是"最终平衡成什么样"。
这课的散度概念是 0010 的伏笔——下一课的不可压约束和它直接挂钩。

✦ 本课收获 ① 见识"椭圆型"问题：没有时间演化，靠迭代到收敛求稳态场（与前面的"时间推进"是两种世界观）；
② 会用 L1 范数收敛判据做迭代停止条件，并首次把代码函数化（plot2D / laplace2d）；
③ 给 Laplace 加一个源项 → Poisson。这是 Step 11 压力泊松方程的直通预告。
◆ 物理补强｜本课会用到的流体力学基石 本课转变世界观，补两个让"迭代稳态"说得通的物理项：
  • 三类偏微分方程的直觉区分：①双曲（002-0004 的对流）：信息沿特征线传播，装在边界上却靠初始条件；②抛物（0005-0008 的扩散）：信息向前"磨"；③椭圆（本课 Laplace）：没有时间、沟通全局，解只由所有边界决定。椭圆问题天然用迭代而非时间推进。
  • 散度 $\nabla\cdot$ 与"流进等于流出"：想要"流过一个闭合面流进的量等于流出的量"（无源、无漏），等价于 $\nabla\cdot\vec v=0$。Laplace 的势函数就是由一个"处处守恒、没有汇聚或发散"的场来描述的。
  • 势函数与偏瑞原理：满足 $\nabla^2 p=0$ 的 $p$ 在任意点取值等于周围均值——这就是迭代法"反复取邻居平均"所以会收敛到平衡的物理根源。
与代码的关系：本课迭代每步把每个格点更新为其四个邻居的平均（Laplace 的离散式），直到变化小于判据。这个"平均-更新-收敛"套路，就是 0010 腔流里压力泊松方程用来保证速度场无源的同一机器。

1 · 换个世界观：没有"时间"的方程

前面 8 步都是 $\partial_t u = \dots$（双曲/抛物，时间推进）。Laplace 方程没有时间：

$$ \frac{\partial^2 p}{\partial x^2}+\frac{\partial^2 p}{\partial y^2}=0 $$

它是椭圆型：描述的是"给定边界条件下系统的平衡态"。温度分布、静电场、不可压流场的压力——全是这类问题。没有 $p^{n+1}$ 了，解"moves toward equilibrium as iterations tend to infinity"：

◆ 迭代法的核心思想 不是"往前推一步"，而是"反复用邻居的平均值刷新自己"，每次迭代让场更平滑、更接近边界给出的约束，直到两次迭代几乎不再变化（收敛）就停止。第 n 次迭代在这里其实是伪时间，不是真实时间。

2 · 离散与五点模板

用中心差分（扩散类物理，必须中心差分——0005 讲过原因）：

$$ \frac{p_{i+1,j}-2p_{i,j}+p_{i-1,j}}{\Delta x^2}+\frac{p_{i,j+1}-2p_{i,j}+p_{i,j-1}}{\Delta y^2}=0 $$

解出 $p_{i,j}$（这就是迭代更新公式）：

$$ p_{i,j} = \frac{\Delta y^2(p_{i+1,j}+p_{i-1,j})+\Delta x^2(p_{i,j+1}+p_{i,j-1})}{2(\Delta x^2+\Delta y^2)} $$

它有个著名的名字：五点差分算子（five-point stencil）——中心 + 上下左右，五个点决定新值。每个格点的"新值"≈ 四个邻居的加权平均。

边界条件（本课的初始化细节）

  • $p=0$ 在 $x=0$；$p=y$ 在 $x=2$（右侧从 0 到 1 渐变）；
  • $\partial p/\partial y=0$ 在 $y=0,1$（Neumann，零梯度——用"等于相邻行"实现）。

3.2 求解函数：迭代到 L1 收敛

def laplace2d(p, y, dx, dy, l1norm_target):
    l1norm = 1                          # 初始置 1，确保进入循环
    pn = numpy.empty_like(p)            # 预分配（占位即可，下面会 copy）

    while l1norm > l1norm_target:       # ← 迭代停止条件：L1 范数低于目标
        pn = p.copy()
        # 内部五点模板一次刷新
        p[1:-1, 1:-1] = ((dy**2 * (pn[1:-1, 2:] + pn[1:-1, 0:-2]) +     # 上下邻居×Δy²
                          dx**2 * (pn[2:, 1:-1] + pn[0:-2, 1:-1])) /    # 左右邻居×Δx²
                         (2 * (dx**2 + dy**2)))

        # 边界条件：每轮刷新后重新施压
        p[:, 0] = 0          # p=0 @ x=0
        p[:, -1] = y         # p=y @ x=2
        p[0, :] = p[1, :]    # ∂p/∂y=0 @ y=0（Neumann：等于相邻一行）
        p[-1, :] = p[-2, :]  # ∂p/∂y=0 @ y=1

        # L1 范数：本次与上次整体差 / 上次整体量 的相对变化
        l1norm = (numpy.sum(numpy.abs(p[:]) - numpy.abs(pn[:])) /
                  numpy.sum(numpy.abs(pn[:])))

    return p
行干什么为什么
while l1norm > l1norm_target只要"还变"就继续迭代没有固定迭代次数，收敛就停——比 for nt 更贴合椭圆问题
p[1:-1,1:-1] = ...五点公式整块刷新内部读 pn（旧值）、写 p（新值）——和前面一致的"读旧写新"纪律
p[0,:] = p[1,:]零梯度边界∂p/∂y=0 用"顶行=第二行"实现，是 Neumann 的差分近似
l1norm = Σ|p|-Σ|pn| / Σ|pn|相对 L1 变化率衡量"场整体变了多少"。官方 target 用 1e-4
◆ 为什么这个循环很慢，还能忍？ 椭圆迭代每轮只把"信息"传播一格，收敛得很慢（官方原话：收敛越来越慢）。Laplace 的简单雅可比迭代是这个价；更快的 SOR / 多重网格是后话。现在重点是理解迭代框架本身。

4 · Step 10：Poisson 方程（加源项）

右边加一个源项 $b$：

$$ \frac{\partial^2p}{\partial x^2}+\frac{\partial^2p}{\partial y^2}=b $$

离散（对应前面公式，多一项 $-b_{i,j}\Delta x^2\Delta y^2$）：

$$ p_{i,j} = \frac{(p_{i+1,j}+p_{i-1,j})\Delta y^2+(p_{i,j+1}+p_{i,j-1})\Delta x^2 - b_{i,j}\Delta x^2\Delta y^2}{2(\Delta x^2+\Delta y^2)} $$

源项设计：域内两个对称"尖峰" $b=+100$ 和 $b=-100$，其余 0；边界全 0。官方提示观察：relaxation under Poisson slows down as they progress——为什么？（因为迭代把尖峰摊开，越平变化越小，L1 变化率越小，后面每轮改善越来越微弱。）

逐行注释：官方 Poisson 主循环

nx = 50; ny = 50; nt = 100
xmin=0; xmax=2; ymin=0; ymax=1
dx = (xmax-xmin)/(nx-1); dy = (ymax-ymin)/(ny-1)

p  = numpy.zeros((ny,nx))   # 压力场初始 0
pd = numpy.zeros((ny,nx))   # 上一轮快照
b  = numpy.zeros((ny,nx))   # 源项场，初始 0
x  = numpy.linspace(xmin,xmax,nx)
y  = numpy.linspace(xmin,xmax,ny)   # 注意官方这里 y 也到 2，稍后留意

# 两个对称尖峰源项
b[int(ny/4), int(nx/4)]      = 100    # 左下角 +100
b[int(3*ny/4), int(3*nx/4)]  = -100   # 右上角 -100

for it in range(nt):                 # 伪时间迭代 100 次（写死次数）
    pd = p.copy()
    # 五点模板 + 源项
    p[1:-1,1:-1] = (((pd[1:-1, 2:] + pd[1:-1, :-2]) * dy**2 +
                     (pd[2:, 1:-1] + pd[:-2, 1:-1]) * dx**2 -
                     b[1:-1, 1:-1] * dx**2 * dy**2) /        # ← 多了这一项
                    (2 * (dx**2 + dy**2)))
    # 四边全 0
    p[0,:] = 0; p[ny-1,:] = 0; p[:,0] = 0; p[:,nx-1] = 0
◆ 官方故意留的"歧义" Step 10 的注释把 y 也 linspace(xmin,xmax,ny)（域到 2），而绘图时 xlim 0..1 是 xy 都到 2 的另一种约定——这里官方代码有点混。你跑的时候留意图形是否与预期"两个对称峰"一致即可，若视觉不对称，检查这行 linspace(0,1,ny) 是否写对。

6 · 检查点：闭卷自测

Q1 · Laplace 与 Poisson 方程的区别是什么？写出两个方程。
Poisson = Laplace + 源项：$\nabla^2 p=0$ vs $\nabla^2 p=b$。源项"放松"域内的峰，非 0 的 b 驱动压力场的不均匀。
Q2 · 五点差分模板是哪五个点？为什么是"邻居平均"？
中心点 + 上、下、左、右。椭圆方程每点新值由四邻决定（各按 Δx/Δy 加权平均），对应"稳态扩散/平衡"的物理本质。
Q3 · 为什么用 while(l1norm>target) 而非固定次数？
椭圆问题没有"真实时间步"，收敛与否只由"两次迭代的变化是否足够小"决定。固定次数可能迭代不足（没收敛）或浪费（早已收敛还在跑）。L1 相对变化率是官方选的收敛度量。
Q4 · 边界 ∂p/∂y=0 在代码里怎么实现？
用零梯度近似：顶行等于第二行 p[0,:] = p[1,:]（底行同理 p[-1,:]=p[-2,:]）——用相邻行的值填充边界，保证沿 y 无变化。
Q5（费曼）· 为什么 Poisson 的迭代"越来越慢"？
每次迭代把尖峰往四周摊一点、场越来越平。越平的地方，"这次和上次差多少"越小，L1 相对变化率越小，判断收敛的阈值越来越难达到——就像把水倒入山谷，越接近平衡水面变化越细微。
