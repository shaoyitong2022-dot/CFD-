◆ 课前补给 · 训练循环的骨架

上一课你做到：明白了裸网络只会插值、不懂物理。→ 这一课往前一步：亲手把训练循环写出来，亲眼看到它出数据区就乱猜。

代码补给⑪（训练四步，所有深度学习的骨架）：

for epoch in range(n_epochs):
    optimizer.zero_grad()   # ① 清空上一轮的梯度
    loss = criterion(y_pred, y_train)   # ② 算损失
    loss.backward()         # ③ 反向传播
    optimizer.step()        # ④ 更新参数

漏掉 zero_grad() 会让梯度累积——这是新手最常见的错误，而且不报错。

物理补给（本轨改补"优化直觉"）：B 轨的物理不再增加，补的是另一件事——优化过程本身。看到裸 NN 在数据区外乱猜，就是"没有归纳偏置"的直接证据。这个失败是故意的，别跳过它。

✦ 本课收获 ① 在 PyTorch 里定义一个全连接网络（FCN）类，看懂 pytorch 的 `nn.Sequential`、`nn.Linear`、`Tanh`；
② 写出一个最标准的训练循环（forward → loss → backward → optimizer.step），并跑通；
③ 亲眼看到裸 NN 在 10 个训练点附近拟合完美、出区间乱猜——为 B4 里"物理救场"做铺垫。
◆ 物理补强｜本课会用到的基石（优化直觉补充） 本课看裸神经网络为什么"只会插值"，补一条核心的机器学习直觉：
  • 插值 vs 泛化：网络能把它见过的（训练区间内的）数据点拟合得很准，这是插值；能被要求预测没见过的（区间外的）输入，才是泛化。裸 NN 没有额外约束时，只有前者——出数据区就"自由发挥"。
  • 训练 = 相对拟合目标做梯度下山：损失函数度量"网络输出离数据有多远"，优化器（Adam）只朝损失减小方向调权重。它没有任何"解该满足物理规律"的意识，所以只要数据稀疏，它就把空间填成最光滑、最容易拟合的形状。
  • "拟合好 ≠ 答对"：10 个点附近 loss 降到很小，只说明网络"背"下了这 10 个点，不说明它理解背后的物理。这是后面强调"物理损失"来弥补的关键缺口。
与代码的关系：训练循环 forward → loss → backward → step 全体作用就是"沿着 loss 关于权重的梯度往下走"。你会在 t>0.4 处看到曲线"乱猜"，那正是"只有数据、没有物理"的直接后果。

1 · 本课的"实验剧本"（回忆 B1）

重复设定：欠阻尼振子 $\delta=2,\omega_0=20$。训练数据只有 10 个点（t∈[0,0.4]），分布在前 0.4 周期。B2 只用数据损失训练：

$$ \text{loss} = \frac1{10}\sum_i (u_{\text{NN}}(t_i)-u_{\text{true}}(t_i))^2 $$

不看答案你也猜得到结局：网络会把已知 10 点拟得丝滑，然后在 t>0.4 处"发挥想象"。这正是我们要亲眼确认的失败。

2 · 逐行注释：FCN 网络类（官方原版）

import numpy as np
import torch
import torch.nn as nn
import matplotlib.pyplot as plt

def oscillator(d, w0, x):
    '''解析解：欠阻尼阻尼振子，官方公式 x(t)=e^{-dt}(2A cos(φ+wt))'''
    w = np.sqrt(w0**2 - d**2)
    phi = np.arctan(-d/w)
    A = 1 / (2*np.cos(phi))
    # 注意：这里全部张量运算（传入的是 torch 张量）
    cos = torch.cos(phi + w*x)
    sin = torch.sin(phi + w*x)
    exp = torch.exp(-d*x)
    return exp * 2 * A * cos

class FCN(nn.Module):
    '''Fully Connected Network（全连接网络）——PINN 的标准骨架'''
    def __init__(self, N_INPUT, N_OUTPUT, N_HIDDEN, N_LAYERS):
        super().__init__()
        activation = nn.Tanh            # 激活函数选 tanh（后面讲为什么）
        # 输入层：Linear(N_INPUT → N_HIDDEN) + Tanh
        self.fcs = nn.Sequential(        # Sequential 把多层串成有序容器
            nn.Linear(N_INPUT, N_HIDDEN),
            activation())
        # 中间层：N_LAYERS-1 个 (Linear(N_HIDDEN,N_HIDDEN) + Tanh)，列表推导批量生成
        self.fch = nn.Sequential(*[
            nn.Sequential(nn.Linear(N_HIDDEN, N_HIDDEN), activation())
            for _ in range(N_LAYERS-1)])
        # 输出层：Linear(N_HIDDEN → N_OUTPUT)
        self.fce = nn.Linear(N_HIDDEN, N_OUTPUT)

    def forward(self, x):
        x = self.fcs(x)   # 输入 → 第一个 Tanh
        x = self.fch(x)   # 中间若干 Tanh
        x = self.fce(x)   # 最后无激活，输出原始值
        return x
元件作用
nn.Linear(in, out)全连接层：y = Wx + b，含可训练权重 W 和偏置 b
nn.Tanh激活函数 tanh，输出在 (-1,1)。选它是因为 sigmoid 类对高阶导数友好（后面求二阶导时稳）
nn.Sequential把线性层+激活层按顺序打包成一个子模块
y = model(x)调用 forward：x 尺寸 (N,1) → 输出 (N,1)
◆ 为什么激活函数对 PINN 重要？ PINN 要计算网络输出对输入的导数，且经常算二阶导。tanh/sigmoid 这类光滑饱和激活可导任意多次，导数行为良好；而 ReLU 的二阶导在 0 处是"断的"，会让物理损失不稳定。这是 PINN 实践中选 tanh 的一个实际理由。

4 · 训练循环（官方原版，逐行注释）

torch.manual_seed(123)                        # 固定随机种子 → 结果可复现
model = FCN(1, 1, 32, 3)                      # 输入1维(t)，输出1维(u)，隐藏32神经元，共3层
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)   # Adam 优化器

for i in range(1000):                         # 训练 1000 步
    optimizer.zero_grad()                     # 清空上一步梯度（不然后面会累加）
    yh = model(x_data)                        # 前向：网络输出预测值
    loss = torch.mean((yh - y_data)**2)       # 均方误差（MSE）
    loss.backward()                           # 反向传播：算出每个参数梯度
    optimizer.step()                          # 沿梯度走一步更新参数

    # （官方每 10 步画一次；结束时你看到数据点附近完美、区间外乱猜）

四行训练节奏（背这句口诀，B3/B4 都会用）：清空梯度 → 前向算损失 → 反向传播 → 优化一步。

◆ torch.manual_seed(123) 为什么重要 神经网络初始化权重是随机的。不加种子，两次运行结果不同，检查和复现都难。加种子=固定随机数，保证"你和我看到的图"一致。写可复现实验的第一习惯。

6 · 检查点：闭卷自测

Q1 · 训练循环四步是什么？
zero_grad（清梯度）→ loss（前向+算损失）→ backward（反向传播）→ step（更新参数）。口诀：清→算→传→更。
Q2 · x_data 为什么有 10 个点？它来自哪些下标？
x[0:200:20]：500 点里只取前 200 个（t≤0.4）、每隔 20 取 1 → 下标 0,20,…,180 共 10 个点。B 轨和 0001 切片是同一招。
Q3 · FCN(1,1,32,3) 各参数是什么意思？
N_INPUT=1（输入 t）、N_OUTPUT=1（输出 u）、N_HIDDEN=32（隐藏层宽度）。N_LAYERS=3 指的是中间隐藏块的数量再加 1：按代码结构，实际是 fcs（1 个 Linear+Tanh）+ fch 里 N_LAYERS-1=2 个 (Linear+Tanh) + fce（1 个 Linear），合计 4 个 Linear 层、3 个 Tanh。所以 N_LAYERS 与其说"总层数"不如说"隐藏块数+1"——层数偏多的时候容易记混，写代码时要回到 FCN 的 fcs/fch/fce 三段结构去数。
Q4 · 为什么 PINN 常用 tanh 而非 ReLU？
要多次求导（torch.autograd 会对输出算一阶、二阶导），tanh 处处光滑可导、导数行为良好；ReLU 二阶导在 0 处不存在，会让物理损失不稳。
Q5（费曼）· 用一句话解释"插值 vs 外推"，并举出本课的实例。
插值=在已知点之间做合理猜测；外推=在已知范围之外猜想。本课：网络在 10 个训练点之间拟得很好（插值 ✓），到 t>0.4 处跟解析解脱节（外推 ✗）。PINN 的意义就是让外推也被物理救回来。
