补给已经内联进每一课的开头了：翻到任意一课，开场那个「◆ 课前补给」块就是它在链条上的位置、需要的新写法与新概念——不用再跳出去查。本页是总览：用来看清"我现在走到哪""整条线长什么样"，以及需要纵深时该去翻哪本书。

怎么用

  1. 从上往下走，不要跳。每条 Stage 里的「补给」先花 20–30 分钟看完，再进主课。
  2. 「你会卡在哪」是预告，不是威胁——提前知道坑在哪，比掉进去再爬出来省时间。
  3. 「过关标准」是可验证的。答不出来就别硬往前推进；但也别死磕——回落到上一 Stage 重复一轮通常更省事。
◆ 两条补给线的脾性完全不同，别用同一种读法 Python 补给 = 字典：不要通读教材。遇到看不懂的写法 → 先查 Python 工具箱 → 还不通才去外部资源查那一节。它是按需检索，不是线性阅读。
流体补给 = 慢炖：反过来，它建议线性推进。物理图像是「存储强度」型知识，临时抱佛脚补不出来——这也是为什么它比代码补给更需要提前一个月开始泡。整个文档里只有 David Tong 讲义建议系统性阅读（每周一小节，与 Stage 1→4 并行）。

Stage 0 · 出发前（半天）

对应主线0001 · 环境点火与 NumPy
你会卡在哪环境本身。Jupyter 起不来、解释器选错、%matplotlib inline 报错。
补给无。本阶段不需要任何额外知识。
过关标准能在 Jupyter 里 import numpy，画出一条 sin 曲线并保存出来。

Stage 1 · 对流与稳定性的第一次交手

对应主线0002–0004 · 线性对流 / 非线性对流 / CFL 专章
你会卡在哪为什么 un = u.copy() 不能省（省了不报错，只是悄悄错）；为什么 dt 调大就炸。
代码补给工具箱 §1 数组创建、§2 copy()（最重要，逐字读完）、§3 负索引
流体补给流体直觉 §1 场、§2 对流＝搬运、§3 特征线与信息传播
一手资源SciPy Lectures §1.4 NumPy——只看数组创建与索引这两部分，约 20 分钟
过关标准能手算 Courant 数；能向别人解释「不写 copy() 为什么结果会静默变错」。

Stage 2 · 二阶导与 Burgers

对应主线0005–0006 · 扩散 / Burgers 方程
你会卡在哪SymPy 到底是干嘛的；那一坨初始条件从哪来的；dt = dx*nu 凭什么能用。（这三个坑 0006 已补详解）
代码补给工具箱 §5 列表推导+asarray、§6 SymPy 三件套、§7 Matplotlib 最小集
流体补给流体直觉 §4 对流 vs 扩散的对立、§5 黏性与雷诺数
一手资源SciPy Lectures §1.4.1.6 Copies and views——解决 Stage 1 没吃透的引用语义
过关标准跑出「数值 vs 解析」两线重合的对照图；能说出 Burgers 的「锯齿」现象是谁制造的、谁在压制它。

Stage 3 · 升维：从一维到二维

对应主线0007–0008 · 二维对流 / 二维扩散与 Burgers
你会卡在哪代码突然从双层 for 循环变成一行切片赋值，认不出来这是同一个东西。ijk 索引约定绕人。
代码补给工具箱 §4 向量化（本 Stage 的重头戏）；broadcasting 概念查 SciPy Lectures 同章
流体补给流体直觉 §2 二维速度场与 u,v 两个分量、§4 扩散的各向同性
过关标准能把一段逐点循环改写为切片写法，并说清「邻居的数组为什么整体平移一格」。

Stage 4 · 椭圆方程与 N-S（流体直觉的总验收）

对应主线0009–0010 · Laplace/Poisson / 二维 N-S 腔流通道流
你会卡在哪压力泊松方程是凭空冒出来的——这是整个 A 轨最大的认知断层点，前面 8 课都没铺垫。
代码补给重温 工具箱 §2 copy()；把求解器封装成函数（迈向 solver.py）
流体补给流体直觉 §6 散度与不可压、§7 物质导数、§8 压力泊松与投影法——本 Stage 全靠它
一手资源David Tong 讲义（此时读到第 3 章）：§1.1.2 物质导数、§3.1 应力与黏性、§3.3 量纲分析与雷诺数、§3.5 边界层
过关标准能解释「为什么不可压流必须先解一个 Poisson 方程才能得到下一步的速度」。
⚠ Stage 4 是整条路的瓶颈，建议提前一个月开 Tong Stage 1–3 的流体概念都是可以在课上「顺手理解」的。但 Stage 4 不行——散度、投影算子的思想需要一个沉淀期。
建议：走到 Stage 1 时就开始每周读 Tong 一小节。到 Stage 4 时你已经泡了四周，那一刻它会由难变易懂。这也是本路线图里唯一希望你「提前」开始的东西。

Stage 5 · B 轨：把物理塞进神经网络

对应主线0011–0015 · PINN 概念 → autograd → PINN 合体 → 三线对比
你会卡在哪create_graph=True 到底在干什么；数据损失和物理损失怎么互相打架。
代码补给此时 Python 底子已经够用，只需 torch 的 torch.autograd（讲义内含）
流体补给没有新概念。谐振子是力学不是流体——这正是 B 轨放在最后的原因
过关标准跑出 0015 的「解析 vs FDM vs PINN」三线对比图（这是组会汇报素材）。
